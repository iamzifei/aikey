# aikey-aivideo · 评测样本

每个样本一对文件：`sample-NN-<描述>.md`（给执行者）和 `sample-NN-答案.md`（只给评分者）。执行者是没看过答案的新 context，结果存 `results/`（结果不进公开包）。评测里**不调用任何生成工具，不花额度**。
