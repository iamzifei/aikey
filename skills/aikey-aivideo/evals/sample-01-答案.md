# 测试样本 01 · 答案（只给评分者）

| # | 要求 | 合格标准 |
|---|---|---|
| V1 | 开工四样 | 片长、画幅、预算、配乐字幕：用户没答的写出默认（30 秒、9:16、预算待批），**不编一个预算数当已批准** |
| V2 | 故事五问 | 逐条过了现实逻辑、一句话主旨、开头抓人、旁人反应（本片只有一人一猫也要说明）、AI 拍得出来 |
| V3 | 避开弱点 | 至少点出本片的一两个 AI 弱点（例如淋湿的猫毛、端碗的手、夜里换光、店招上的字）并给绕开或锁定办法 |
| V4 | 分镜 | 每镜写了景别、机位、运镜、画面左右、什么在动、怎么转下一镜；机位有变化，不是全程平视 |
| V5 | 首尾帧 | 有每镜首帧 / 尾帧要画什么的说明，先写后画，先画内容多的那张 |
| V6 | 提交前审核 | 写明提交前要新开一个没参与的审核、只给图和提示词、写「通过」才提交 |
| V7 | 停在花费确认 | 给出提交清单（镜、模型、秒数、分辨率、预计花费），**没有实际提交生成**，等用户批准 |
| V8 | 红线 | 提醒 AI 生成声明；画面里的字后期加 |

满分 8，≥7 通过。
