# 镜头与画面（第 2、3 步用）

> 分镜决定一条片子的质量上限：故事再好，镜头没设计，画面就是平的。
> 镜头语言很难用嘴说清，**最省事的办法是找一条参考片**：逐帧看，把机位、人物进出画面的位置和比例量出来，照着学。找不到参考片，就照下面几条自己设计。

## 一 · 分镜表：一镜占一行

| 栏 | 写什么 |
|---|---|
| 片中时间 | 这一镜落在成片的第几秒到第几秒；有配乐就用小节来定 |
| 生成秒数 | 比片中时长多要一点（取整后再留出约半秒），剪辑时有余量 |
| 景别 | 远景 / 全身 / 半身 / 近景 / 特写 |
| 机位 | 平视、俯拍、仰拍、背后、过肩、透过某个东西拍 |
| 运镜 | 不动 / 推近 / 拉远 / 跟拍 / 横移 |
| 人往哪走 | **用屏幕的左右来写**（「从屏幕右边进来，停在左边三分之一处」） |
| 靠什么推进 | 这一镜靠哪个表情、哪个动作把故事往前推 |
| 什么在动 | 见第三节，至少写出一样 |
| 怎么转下一镜 | 硬切 / 被某个东西盖住屏幕带过去 / 跟着一个东西出画 |

## 二 · 让画面不死的五条

1. **机位别重复**：同一个角度连用两次，观众就会觉得「又是这个画面」。正面平视留给最要紧的一两镜，其余从高处往下看、从低处往上看、从人物身后看、隔着前景（门框、蒸汽、雨帘）看。
2. **远近交替**：上一镜拍全身，下一镜就换半身或特写；连续三镜一样远，节奏就塌了。
3. **每一镜都得有东西在变**：一个人坐着不动、背景也不动，屏幕上就只是一张照片。最好用的是「入画 / 出画」：人或物从画框外进来、或者离开。主角只能坐着时，就让周围动起来：门外过了一辆车、桌上的热气在飘。摄影机不动的镜头最容易僵，更要让人在画面里从远走近。
4. **摄影机动一下，要有一样东西想给观众看**：跟着某个人或物走；慢慢靠近，把注意力收到一个细节上；从一个细节慢慢退开，交代它在什么地方。没有要给观众看的东西就别动，全片晃个不停只会让人晕。
5. **任何一帧截下来都能当海报**：主体的眼睛别放在画面正中，放在左右大约三分之一处（38% 或 62%）。

## 三 · 写每一镜之前先问：这一镜到底什么在动？

候选：机位在移动 · 清楚的地方从前景换到后景 · 光线在变化 · 镜头前掠过一样东西 · 人物一个很小的动作（手指收紧）。**至少挑一样写下来**；一样也挑不出，这一镜就还没设计完。

## 四 · 配色单独设计，不交给模型自己发挥

- 画第一张图之前就定好配色，按他的喜好来。
- **把每场戏的主色、辅色、强调色整理成一张表**，之后的每张图、每份提示词都照这张表来。
- **黑白检查**：把画面转成黑白看一遍，人和背景分不开 → 明暗对比不够，重新调色。

## 五 · 画风与设定图（第 3 步）

- **画风**：用一句话定下来，比如「扁平的二维动画，大色块、细描边、画面干净不加噪点」。有参考图最好，直接给。你写提示词、生成工具出样帧、他看是不是想要的。
- **设定图**：每个角色一张：正面、侧面、几个表情，相当于把长相定死；每件固定道具一张。
- 🔴 **固定特征写清在哪一边**：纹身在左手臂、伤疤在右眉。不写，后面每张图位置都可能不一样。
- 画风和设定图他认可之后再往下走；后面所有图都以它们为准。
