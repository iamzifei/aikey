# 首尾帧与提示词（第 1、4、5 步用）

## 一 · AI 视频的固定弱点：写故事时就绕开

这些画面很难一次生成对，**在第 1 步写故事时就尽量不用**：

- **人和人的位置关系**：两个人互相穿过、换位，脸和身体容易粘在一起
- **小物件**：手里捏着筷子、钥匙、手机，物件容易变形或凭空消失
- **字和镜面**：招牌、屏幕上的字会乱码；镜子和水面里的倒影对不上
- **只长在一边的特征**：左脸的痣、右手的戒指，生成几次就会跑到另一边
- **一镜里变化太多**：同一镜里灯光突然变、一个人接连做好几个动作
- **看不到脸的机位**：从正上方往下拍，人物身份最容易漂
- **人太多**：画面里除了主角还有一群人，每个人都可能走样

非用不可的，在首尾帧里把它画出来锁住（见第二节），并在审核 ②a、②b 里重点查。

## 二 · 首尾帧：少重抽的头号办法

只给文字让模型直接出视频，前后逻辑很容易乱；雨、帽子、纹身这类小东西只写在文字里，生成到一半常常就不见了。**所以每个镜头先画第一张画面（首帧）和最后一张画面（尾帧），再拿两张图去生成视频。**

⚠️ 先查你用的生成工具文档：**有的工具在「首帧 + 尾帧」模式下不能再同时传人物参考图**。那样人和道具长什么样全靠首尾帧锁住，首尾帧必须照设定图画对。

画的顺序：

1. **先写、后画**：每一镜先用文字写清起始画面、结束画面和两者之间的变化，审过再动手画。图的额度比文字贵。
2. **先画内容多的那张**（一般是尾帧），再在它上面改出首帧，这样两张的机位和构图一致。
3. **同一地点、同一机位的镜头，在前一张图上局部改**，不重画。
4. **要慢慢推近的镜头**：把首帧的局部截出来放大，当作尾帧。首尾两张构图完全一样，视频就不会有推近的效果。
5. **尺寸**：生成出来的图不一定正好是目标画幅，提交前检查，首帧和尾帧要裁成同样的尺寸和比例。

画完逐张放大检查：

- 这一镜里会被用上的物件，第一张画面就得看得见（后面要端碗，开头桌上就要有那只碗，不然它会凭空出现）
- 需要拍到旁人反应的，开场就把人站好：生成的这一段中间没法切到另一个角度，所以起始画面就要排好谁在前景动手、谁在后景正对镜头
- 很多人同框时，姿势不要一样（一样的姿势生成出来会同时动）
- 和设定图对得上：脸、衣服、固定特征在哪一边
- 和色表、前后镜头对得上

## 三 · 视频提示词：按秒写，一镜一份

骨架的**顺序**沿用 `aikey-drama/references/分镜与生成提示词.md` 第二节（参考 → 全局 → 固定 → 时间轴 → 声音 → 约束）。两份放在一起读时，**以下三处以本技能为准**：
- 开头那一小段「画面静止、和首帧一样」是给首尾帧模式用的，不受「短于 1 秒的镜头拿不出来」那条限制（它不是一个镜头，是这一镜的起始状态）
- 首尾帧模式下工具不让同时传人物参考图的，就不传，靠首尾帧锁长相
- 不另出草稿版：第一次就按正式镜头生成（有首尾帧兜底）；没有首尾帧的镜头，仍按 drama 的「先便宜档出草稿」

本技能多加三样：

1. **画风一句写在最前**，并要求这一段从头到尾的绘画风格、用色和角色长相，都和两张参考帧保持一致。
2. **时间轴写到每一小段**：开头约 0.2 秒写「画面静止，和首帧一样」；每一段写这段在动的是什么、从什么状态到什么状态；最后一段写「停在和尾帧一样的画面」。
3. **每个动作写原因**：为什么动、手放在哪里。没有原因的动作，模型会自己补一个。

## 四 · 模型最常犯的错，和管用的写法

出了问题**先怀疑提示词，再怀疑模型**。写完对着这张表查一遍：

| 常犯的错 | 写法 |
|---|---|
| 好几个人动作整齐划一 | 给每个人排一个时间点（「店员先抬头，过一会儿客人才回头，最后小孩跑过来」），首帧里每个人的姿势也各不相同 |
| 本该由风、水流或机器带动的东西，被人伸手去推 | 先写清是什么在带动它，再明确写人的手在哪里、全程没有碰它 |
| 自然景物（云、月亮、花）被画出五官 | 去掉「卡通」「可爱」这类形容，只写它真实的材质、颜色和怎么移动 |
| 小道具消失、变数量、变大小 | 首帧尾帧都画上；提示词里写明数量和位置 |
| 左右写反 | 一律写「画面左 / 画面右」，不写「他的左手」 |
| 自己配上音乐 | 写「没有音乐，只有环境声」；还混进来的，声音后期另加 |
