# aikey-cover：一套封面图

先读 `aikey/references/家族公约.md`（读不到 → 明说「公约读不到，红线无法保证」并停下，**不凭记忆代替公约**），再读 `aikey/references/交互规范.md`（🔴 收尾按 §四 三件套 —— Recap · Before/After · **下一步给编号选项**；缺信息按 §四 用**选择题**问，**一次只问一个**；不适用的情况见 §五），再读记忆 `{vault}/08-技能记忆/aikey-cover/` + `_通用/`。判据在 `references/规则卡.md`，平台与比例的起点表在 `references/平台尺寸表.md`，开工前都读一遍。

这个技能存在的理由只有三条，别的模型也会画图：

1. **一个比例一次排版**。同一张图拉成四个比例，人脸和大字一定有一版被切
2. **封面字过红线**。封面是观众先看到的门面，违禁词、卖真、不点名在这里最贵
3. **交付是核过的**。文件名写着 16:9 不算数，读出来的像素才算

## 第一步：凑齐三样输入

| 输入 | 缺了怎么办 |
|---|---|
| **人物素材图**（本人照片 / 视频截帧） | 问。🔴 不拿别人的脸、图库人像、上一条的截图顶替 |
| **背景图**（场景、产品界面、氛围图） | 问；用户说「不要背景」就用纯色或渐变底，照说 |
| **主题**（这条讲什么，或直接给封面字） | 问。有稿 / 有片子就读稿 / 读片子，不只凭一句话 |

素材先看一遍，说清两张图各自的角色（谁是主体、背景留哪些元素）。缺几样一次说全，但按交互规范**一次只问一个选择题**。

**片子拍到哪一步了？** 按 `aikey-title/references/拍摄进度分档.md` 判。片子拍完不能补拍的，封面只承诺片子里真有的东西。

## 第二步：封面字（归口调用 /aikey-title）

按家族公约〈八〉②归口调用：读 `/aikey-title` 的判据，当场定封面大字，**在报告里写明用了它的哪个结构编号**。

- 用户给了精确的字 → 原样用，但照样过红线；过不了就说哪一处、给改法，不擅自改
- 没给 → 从主题 / 稿子提炼，每行字数守 `platforms[].cover_text_limit`；平台没配这一项就按 `/aikey-title` 对该平台的口径
- 要两种语言 → 一种语言一张图，**两种语言意思一致、各自说得自然**，不在一张图里堆双语。只给了一种，另一种忠实翻译，不加原文没有的数字和结论
- 红线按公约〈三〉，**平台差异照算**：给国内公域平台的那版全套生效，`domestic_public: false` 的平台按其规则

## 第三步：定交付清单

读 `config.yaml` 的 `platforms`，对照 `references/平台尺寸表.md` 算出这次要哪些「语言 × 比例」。

- 能算出来 → 列成表给用户看一眼，**直接开做**，不逐项问尺寸、目录、风格
- `platforms` 里有平台不在尺寸表里 → 只问这一个平台要什么比例
- 用户当次点名了平台、语言、尺寸或张数 → 以当次为准
- 只补一张（比如只缺 B 站 16:9、只缺 Instagram 9:16）→ 只做缺的那张，不重做全套

文件名必须带**语言 + 比例 + 横竖**，例：`中文-3比4-竖版.png`、`英文-9比16-竖版.png`、`中文-16比9-横版.png`。改版本加后缀在扩展名前：`中文-4比3-横版-v2.png`。

## 第四步：出图

用当前环境里**能吃参考图的**图像生成 / 编辑工具。环境里指定了图像模型就用它，凭据从环境变量读，**绝不写进任何文件**。

- **每个「语言 × 比例」单独生成一次**，提示词写清：目标比例和像素、封面字原文和语言、人物图与背景图各自的角色、要保留的人物特征和配色
- **每一次都把两张原始素材喂进去**。只拿上一张成图改下一张，人会越改越不像。工具允许时可以把第一张成图额外当风格参考
- 一套之内人物、配色、字体风格一致；各比例按自己的画布重排人物、文字、留白
- 不加水印、不加平台 logo、不换人
- **中文字是 AI 出图最不稳的地方**。同一张字出错两次 → 换路：生成**无字底图**，字用 HTML 排版后截图叠上去（字可控），在制作说明里记下换了路
- 没有可用的图像工具 → 明说，交付「每张的提示词 + 排版方案」，**不自动切到要另付费的接口**

## 第五步：核验

逐张看图，再用只读工具读**实际像素**（如 `sips -g pixelWidth -g pixelHeight`、`python3 -c` 读 PIL）。逐项过：

- 清单里每个「语言 × 比例」都有，比例对（文件名不算证据）
- 封面字逐字对，没有错字、缺字、乱码
- 人脸和大字不贴边、不截断；有安全区要求的比例按规则卡核
- 人物是同一个人，没有明显畸形

不合格的那张单独重做；做不到目标尺寸就报**实际尺寸**和没完成的项。**全部核过才说完成**，部分失败时保留合格的，只补失败的。

## 第六步：落盘

目录：`{vault}/{config.paths.drafts}/封面/YYYY-MM-DD-主题/`

- 日期取用户本地当天，用户指定就用指定的
- 主题保留中文，去掉 `/` 等不能进文件名的字符，**不把主题当路径解释**
- 同一天同名目录已存在：新任务加 `-02`、`-03`；改的是同一套 → 复用目录、新文件加 `-v2`，**不覆盖**，除非用户明说覆盖
- 成图从工具的输出位置**复制**进来，按工具返回的真实路径找文件，不猜路径
- 原始素材不动

同目录写 `制作说明.md`：主题、各语言封面字（及 /aikey-title 结构编号）、每张图的语言 / 文件名 / 实际像素、最终提示词、用的工具、有没有换成 HTML 叠字。下次改图从这里接着改。

## 交付

```
## 封面：[主题]　｜　片子进度：[档]　｜　目录：[绝对路径]
| 文件 | 语言 | 比例 | 实际像素 | 给哪个平台 |
|---|---|---|---|---|
封面字：[中文] / [英文]　｜　结构：S[编号]（/aikey-title）　｜　红线：[✓ / 改了哪处]
未完成：[无 / 哪张、为什么]
```

收尾按交互规范三件套。下一步选项通常是：改某一张 / 补一个平台的比例 / 去发（发完回 `/aikey-retro`）。

## 绝对不做

- 不发布、不上传。做图到落盘为止
- 不拉伸、不裁切现成的一张去冒充别的比例
- 不用缺失素材的替代品（别人的脸、旧图、图库人像）
- 不声称某个边距「所有平台都不会挡」。安全区是设计基线，平台实际裁切以上传界面为准
- 不在封面字里加原稿没有的数字、成果、承诺
