# 平台尺寸表

> **这是起点，不是规定。** 平台会改上传界面和裁切方式，最终以当次上传界面的实际预览为准。
> 发现哪里和实际不一样 → 记进技能记忆，并回来改这张表。
> 比例一律写「宽:高」。像素是首选目标，比例是必须核的交付条件。

## 比例 → 首选像素

| 比例 | 横竖 | 首选像素 | 文件名片段 |
|---|---|---|---|
| 3:4 | 竖版 | 1536×2048 | `3比4-竖版` |
| 9:16 | 长竖版 | 1152×2048（或 1080×1920） | `9比16-竖版` |
| 4:3 | 横版 | 2048×1536 | `4比3-横版` |
| 16:9 | 宽屏横版 | 2048×1152 | `16比9-横版` |

## 平台 → 要哪些比例

`config.yaml` 里 `platforms[].id` 对这一列。不在表里的平台，问用户，不猜。

| 平台 id | 平台 | 封面比例 | 备注 |
|---|---|---|---|
| `douyin` | 抖音 | 3:4；横版视频另加 4:3 | |
| `xiaohongshu` | 小红书 | 3:4 | |
