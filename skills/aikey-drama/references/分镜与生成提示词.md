# 分镜与生成提示词（Phase 7 用）

> **给执行者看。** 剧本定稿之后、用户要「拍成 AI 视频」时才用。
>
> 🔴 **这里的写法来自公开的提示词案例，是经验写法，不是模型保证。** 同一条提示词每次出片会不一样。
> 本技能**没有实测出片**；交付时照实说「提示词按常见写法写的，出片要试」。
>
> 🔴 **生成本身不在本技能里做。** 要出片 → 按家族公约「归口调用」交给 `chatcut-video-gen`（需要 ChatCut 付费额度）。
> 本文件只管把剧本写成它能直接用的提示词。**模型参数以 `chatcut-video-gen` 自己的文档为准**，下面写的是 2026-09 核过的口径。

---

## 〇、模型与时长（先定这个，后面都跟着它）

| 模型（`chatcut-video-gen` 里的名字） | 每条时长 | 用途 |
|---|---|---|
| `seedance-2-5` | 4–30 秒 | 默认；定稿 |
| `seedance2` | 4–15 秒 | 需要 2.0 的效果 |
| `seedance2fast` | 4–15 秒，最高 720p | 快速迭代 |
| `seedance2mini` | 4–15 秒，最高 720p，约一半价钱 | 便宜出草稿 |

🔴 **默认每条 ≤15 秒**：这样四个模型都能跑，草稿用 `seedance2mini` / `seedance2fast`、定稿换 `seedance-2-5` 不用重切。
**只有确定草稿和定稿都用 `seedance-2-5` 时**，同一场、同一批人、同一地点才写到 16–30 秒；超过 30 秒一律拆开（身份漂移明显变多）。

## 一、先切：剧本 → 分镜表

| 判据 | 做法 |
|---|---|
| 每条的长度 | 见第〇节；**以剧本估的时长为准**，分镜不许把戏拉长 |
| 每条里分几段 | **每段 2–5 秒**，首尾相接，加起来等于这条的总时长 |
| 每段写什么 | **一个主要动作、一种运镜**。一段里塞几个动作，模型会省掉或乱剪；两种运镜叠在一段里会打架 |
| 太短的镜头 | **短于约 1 秒的拿不出来**，并进相邻一段 |
| 两个人同框、都面对镜头 | 容易换脸：给每人写**位置 + 服装**，这一段用**固定机位** |
| 换场、换人、换地点 | 另起一条 |

分镜表（先给用户看，他点头再写提示词）：

```
| 条 | 对应剧本 | 时长 | 段落（每段一行：时间 · 景别 · 运镜 · 动作） | 出场人物与道具 | 本条参考图 |
|---|---|---|---|---|---|
| 1 | 场 1 · 0:00–0:08 | 8 秒 | 0–3s Close-up · 固定 · 门猛地拉开 / 3–8s Close-up · Push-in · 提绳勒进指节 | 老周、陆明远 | 老周定妆图、陆明远定妆图 |
```

## 二、一条提示词的骨架（按这个顺序写，不要打乱）

```
【参考】@图片1 是老周（定妆图），@图片2 是陆明远（定妆图）。
【全局】时长 {N} 秒 · 竖屏 9:16 · {风格：写实电视剧质感 / 手机实拍感 / …}
【固定】（只写一次，后面不再重复）
  @图片1 老周：继承脸、发型、服装；不继承参考图的背景、姿势、构图、光线。{发型} · {上衣} · {下装} · {鞋} · {随身物}
  地点：{一句话，含时间、光线}
【时间轴】
  [0–3s] 镜头1（Close-up，固定机位）：{开始时 → 发生什么 → 结束时}
  [3–8s] 镜头2（Close-up，Push-in）：……
【声音】{这条要什么声音：台词 / 环境声 / 安静}；台词按第四节写
【约束】画面里不出现任何文字、字幕、logo。人物面部稳定、不变形，手和手指结构正确。结尾硬切，不要淡出。
```

写法要点：

1. **全局在前，约束在后。** 负向和硬约束放最后一块，**不要塞进某一段里**——塞进去就只对那一段生效
2. **固定块只写一次。** 每段都重写衣服，反而会让衣服在段与段之间突变
3. **景别和运镜用英文原词写在括号里**，动作描述用中文。常用词：Close-up、Medium Shot、Full Shot、Long Shot；Low Angle、High Angle、Eye-level、Over-the-shoulder；Push-in、Pull-out、Pan、Dolly/Track、Following Shot、Orbit；Slow Motion、Handheld Feel
4. **每段写「开始时 → 发生什么 → 结束时」**，下一段才接得上
5. **开场在动作中间**，第一秒就是动作进行到一半——和剧本的开场爆点是同一件事
6. **结尾写「硬切」**，不写淡出
7. **反转写成一个具体画面**（「外套底下露出一顶黄色头盔」），不写「令人震惊的真相」
8. **末尾加稳定性要求**（面部稳定、手指正确），带人脸的镜头默认都加
9. 🔴 **中文提示词不超过 500 字**；写长了模型会丢细节。继承 / 不继承压成一行，不要展开

## 三、参考图怎么引用（人物和关键道具）

🔴 **编号不是名字，是这一次请求里的顺序。** `chatcut-video-gen` 按参考图在请求里的排列顺序编号：第一张是 `@图片1`（或 `@Image1`），第二张是 `@图片2`……同一张图在两次请求里排的位置不同，编号就不同。

所以：

1. **每一条提示词的第一行写「参考」**，把这一条传的每张图和它是谁对上：`@图片1 是老周（定妆图），@图片2 是黄色头盔`
2. **只传这一条出场的人和道具**，不传不出场的——传了但不出场，模型可能把他塞进画面
3. **编号后面紧跟名词**：写「@图片1 老周推开门」，不写「@图片1推开门」「@图片2位于左边」。编号后面直接接动词或数字，模型可能读错
4. 写明**继承什么**（脸、发型、服装、配饰）和**不继承什么**（参考图的背景、姿势、构图、光线）。不写不继承，模型常把参考图当风格图
5. 转头、被遮挡、快速动作的那一段，**再重申一次**「同一张脸」
6. **反转靠某个道具时，道具也要锁**：单独一张道具图，写明颜色和外形；**不要求画出品牌 logo**（生成的字是乱的，约束里也禁了）

**参考图从哪来**：
- 🔴 **真人照片直接上传可能被拒**；生成出来的写实人脸也**不保证能被当参考图接收**
- 更稳的做法：用有授权的人像素材；或者先用图像模型按剧本里的人物说明（单集是「人物」那一节，连续剧是人物小传）出一张**非写实**的定妆图
- 🔴 **出定妆图也要花额度**，列进第六节的确认表
- 被拒了就报给用户，换一张，**不要拿同一张图反复重试**

## 四、声音与台词

🔴 **Seedance 生成时一定带声音**（音乐、旁白、环境声都会出），没有关掉的开关。所以每一条都要**写清楚要什么声音**。

- **台词**：语言单独写一行（「语言：中文普通话」），放在台词前；**一拍只让一个人说**；每拍约 3 秒、台词短（中文十来个字以内），长台词拆几拍。**时长仍以剧本为准**：拍数排不下就合并台词或删句，不把戏拉长
- **反应写成因果**：「B 说完 → A 手指一紧 → A 抬眼」，每拍用一行结束状态收尾
- **不要声音的地方写「安静」**，否则模型会自己配乐
- 🔴 **跨条要保持的声音，交给后期**：每一条各自生成，人物嗓音、同一个提示音在不同条里会不一样。剧情靠「同一句话、同一个声音」成立的（例如反转靠两部手机同一声提示音），**这个声音后期统一加**，或者用 `seedance-2-5` 的音频参考（`@音频1`）锁住
- **品牌名、数字、手机屏幕上的字，全部后期加字幕**

---

## 五、要不要先出分镜图

多镜头、动作顺序很重要的一条（打斗、反转那一段），可以先出一张分镜图再转视频：

1. 用图像模型出**一张带编号格子的分镜页**：每格写「景别 + 正在发生的动作」，格数按每格 1.5–3 秒倒推
2. 🔴 **不要把时间码画进分镜图**，会被当成画面内容带进视频
3. 视频提示词里写清分工：**人物参考图只管长相，分镜图管地点、动作、构图和顺序**；「按 1 到 N 的顺序，每格一个镜头，不跳步」
4. 分镜图本身也要花额度，列进确认表
