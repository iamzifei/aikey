# 剧本格式（两种交付）

> 标点按 `aikey/references/交互规范.md` §一：中文剧本用中文标点，引号一律用弯引号 “ ”。

---

## 通用：一场戏怎么写

```
【场 3】日 · 内 · 公司茶水间
（林晚端着咖啡转身，正撞上陈总。咖啡泼了他一身。）
陈总：（低头看西装，笑）新来的？
林晚：（没道歉，盯着他胸牌）您就是陈总？
【镜头】特写：林晚握杯的手指发白。
```

- **场头**：场号 · 日/夜 · 内/外 · 地点
- **动作**写在（）里，只写**看得见、拍得出**的东西；不写「她很紧张」，写「手指发白」
- **台词**：人名＋冒号＋台词；括号里的表演提示尽量短
- **【镜头】**只在必须指定时写（特写、反应、手机屏幕）。竖屏多写脸和手
- **时长估算（粗估，不是标准）**：中文台词大约每秒 4–5 个字，一行动作给 2–3 秒；写完按这个估一下这集多长，**真拍时以念一遍计时为准**

## A · 单集短剧（1–3 分钟）

```markdown
# {标题}

- 一句话卖点：{谁} 在 {什么处境} 下，{要做什么}，却 {撞上什么}
- 时长：约 {N} 秒　·　人物：{2–3 个}　·　场景：{1–3 个}
- 开头用的是：{开头六式之一}　·　结尾用的是：{落地式 / 留问式}

## 人物
- {名字}：{一句话身份} ·“{最能代表他的一句台词}”

## 剧本
{按「通用」格式写全，每场标 0:00 这样的大约时间点}

## 反转的伏笔
- 反转：{第几秒，翻的是什么}
- 伏笔：{第几秒，那个当时不起眼的细节}

## 拍摄备注
- 竖屏机位 / 必需道具 / 一个人能不能拍完（不能的话缺几个人）

## 自检表
{SKILL.md Phase 5 那张表，逐项填 ✅ / ⚠️ + 一句理由；卡点那一项写「不适用」}
```

## B · 付费连续剧开发包

```markdown
# {剧名}

## 一、一句话卖点
## 二、基本信息
- 总集数：{N}　·　单集时长：{秒}　·　给谁看：{国内付费 / 海外 / …}　·　类型：{…}
- 付费卡点（按 80 集常见做法换算）：第 {a} / {b} / {c} 集
## 三、故事梗概（300 字以内，写到结局）
## 四、人物小传（3–5 人）
- {名字}｜{身份}｜要什么｜怕什么｜藏着什么｜和主角的关系怎么变
## 五、分集大纲
| 集 | 这一集发生了什么（一句） | 结尾停在哪 | 卡点 |
|---|---|---|---|
| 1 | … | … | |
| … | | | |
| {a} | … | … | ★ 第一卡 |
（全部 N 集，每集一行；四段各自的开头集加粗）
## 六、前 3 集完整剧本
### 第 1 集
{按「通用」格式写全；标出四拍大约落在哪一秒}
### 第 2 集
### 第 3 集
## 七、自检表
{SKILL.md Phase 5 那张表，逐项填 ✅ / ⚠️ + 一句理由}
```

**分集大纲的结尾那一列不能空**：每集停在哪，是这一行最重要的信息。空着＝这一集还没想好。
