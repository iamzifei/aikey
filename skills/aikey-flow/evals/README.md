# aikey-flow · 评测样本

每个样本一对文件：`sample-NN-<描述>.md`（给执行者）和 `sample-NN-答案.md`（只给评分者）。
执行者是一个**没看过答案的新 context**，拿 SKILL.md + 样本跑出报告，报告存到 `results/sample-NN-v<版本>.md`。
