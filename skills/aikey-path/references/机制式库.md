# 机制式库 · 常见目标怎么拆

> 关二要的那个式子。**库里有就直接用，没有就按最后一节现场推。**
>
> 🔴 **每条的「常见瓶颈」都是经验判断，不是这个人的实际情况。**
> 它只用来**决定先去量哪个因子**，不用来替他下结论。真正的瓶颈由关三的三问定，且要他确认。

---

## 三种式子，先分清用哪种

| 形状 | 什么时候用 | 例 |
|---|---|---|
| **乘法（漏斗）** | 一件事要连续闯过好几道关，**任何一关是零，结果就是零** | 曝光 × 点进 × 留下 × 下单 |
| **加法（来源）** | 几个来源各自独立贡献，**一个断了其余还在** | 营收 = A 渠道 + B 渠道 + C 渠道 |
| **存量 = 流量的累积** | 目标是个**存量**（粉丝数、存款、库存），但你每天能动的只有流量 | 粉丝 = Σ（新增 − 取关） |

🔴 **最常见的错误是拿乘法去套存量目标。** 「涨到一万粉」不是一个乘法能算出来的数，它是**每天的净增累积**——
所以第一步永远不是「我要一万粉」，是「现在每周净增多少，要变成多少」。

## 生意类

### 赚到 X 钱（任何生意通用）

```
一段时间的营收 = 客户数 × 每人买几次 × 每次多少钱
利润 = 营收 × 毛利率 − 固定开销
```

| 因子 | 怎么量 | 谁能动它 |
|---|---|---|
| 客户数 | 数订单里的不重复的人 | 获客动作 |
| 每人买几次 | 同一个人一段时间内的订单数 | 复购、续费、召回 |
| 每次多少钱 | 营收 ÷ 订单数 | 定价、套餐、加购 |

**常见误拆**：直接拆成「线上 + 线下」。那是加法式的来源拆分，**没有告诉你该动什么**——两边都还得再拆一次上面这三个因子。

**常见瓶颈（经验，待他确认）**：刚起步在**客户数**；有一批老客户之后通常在**每人买几次**（这一格最便宜，因为不用重新获客）。

**对照项**：推客户数 → 盯**毛利率**和**退款率**（打折拉新最容易同时毁掉这两个）。

### 从零到第一笔收入（副业 / 新线）

```
第一笔收入 = 接触到的人数 × 愿意聊的比例 × 聊完愿意付的比例
```

**这个式子的全部价值在于：它把「我要赚钱」变成了「我这周要接触多少人」。**

**常见误拆**：拆成「做产品 → 做流量 → 变现」。那是**阶段**不是因子——阶段没法量，也没法判断哪一段卡住。

**常见瓶颈（经验）**：几乎总在**第一格**，而且常常是个位数。
判据：过去三十天你**主动**跟多少个可能的买家说过话？答案是「没算过」或者「几个」时，后面两格再优化都没意义。

**对照项**：接触人数上去时盯**每次接触的质量**（有没有变成群发）。

### 涨价 / 提高客单

```
涨价后的营收 = 原客户数 × 留下来的比例 × 新价格
```

**关键判据**：**多少人走了，这件事才开始亏？** 先算这个数，再决定涨不涨。
（涨价涉及老客户的，先看 `/aikey-concentration` 的禁止动作清单——**大客户满意的时候不要主动去惊动他。**）

## 内容类

### 涨到 X 粉 · 抖音 / 视频号（看完型）

```
净增 = 发了几条 × 每条平均曝光 × 完播率 × 关注转化率 − 取关
到 X 粉要多久 = （X − 现在） ÷ 每周净增
```

| 因子 | 在哪看 | 动它靠什么 |
|---|---|---|
| 条数 | 自己数 | 产能、流程 |
| 每条曝光 | 后台播放量 | 选题（决定推不推得出去） |
| 完播 / 留存 | 后台完播率、前几秒留存 | 开头和节奏 |
| 关注转化 | 涨粉 ÷ 播放 | 这条有没有给出「值得长期跟」的理由 |

**常见误拆**：只盯「涨粉数」这一个数。它是四个因子的乘积，**不拆开就不知道该改哪儿**——
曝光低是选题问题，完播低是开头问题，两个的动作完全相反。

**常见瓶颈（经验）**：起号期在**曝光**（也就是选题），不在剪辑。

**对照项**：推条数 → 盯**单条平均表现**；推曝光 → 盯**取关数和完播率**。

### 涨到 X 粉 · 小红书（点进型）

🔴 **不要拿上面那条直接套小红书。** 两边的漏斗形状不一样：视频是「推出去 → 看完 → 关注」，图文笔记是「**推出去 → 看到封面标题 → 点进来 → 看完 → 关注**」——
**中间多了一道「点不点进来」，而那一道由封面和标题决定。**

```
每周净涨粉 = 发几篇 × 每篇曝光 × 点进比例 × 点进后看完的比例 × 关注转化 − 取关
到 X 粉要多久 = （X − 现在） ÷ 每周净涨粉
```

| 因子 | 在哪看（开了专业号，数据中心里有） | 卡住了动什么 |
|---|---|---|
| 发几篇 | 自己数 | 产能、工作流 ← **多数人问的「用哪个 AI」只能动这一格** |
| 每篇曝光 | 笔记的浏览量 | 选题（决定平台推不推、搜不搜得到） |
| 点进比例 | 有的后台给点击率；没有就用「浏览 ÷ 曝光」近似 | **封面 + 标题**（这一格是小红书独有的大头） |
| 看完 / 互动 | 点赞、收藏、评论、阅读时长 | 正文结构、有没有值得存下来的东西 |
| 关注转化 | 涨粉 ÷ 浏览 | 这篇给没给「值得长期跟」的理由 |

**三条与视频号不同的形状（写路径时会用到）**：

1. **有搜索入口，笔记有长尾** —— 一篇好笔记发出去几周后还在带人来，所以**选题里「有人会去搜」这件事比视频侧更值钱**
2. **收藏比点赞更能说明价值**（收藏 = 「我以后要用」）—— 育儿、教程、清单这类尤其明显
3. **封面是独立的一道关** —— 视频侧封面和开头常常一起管用，图文侧它是**唯一**决定点不点进来的东西

⚠️ **这三条来自平台公开形态和后台流量来源，属于常识与推断，不是本系统实测的数据。** 当线索用，别当定律。

**常见瓶颈（经验，待他确认）**：起号期在**曝光**和**点进比例**两格之间——
判据是看浏览量的**分布而不是平均**：十篇都是两三百 → 卡在曝光（选题）；有几篇上千但多数很低 → 卡在稳定性，也是选题；浏览高但没人点进/不涨粉 → 卡在封面标题或关注理由。

🔴 **不许拿平均值判断。** 十篇里一篇一万、九篇两百，平均一千二，看起来很健康，实际是一次偶然。

**对照项**：推发文量 → 盯**单篇平均浏览**；推点进比例 → 盯**看完和收藏**（标题党能把点进拉上去，代价是点进来就走，平台随后就不推了）。

🔴 **内容目标拆到这一步就该交棒**：选题去 `/aikey-topic`，开头去 `/aikey-hook`，数据回流去 `/aikey-retro`。
**本技能只负责把「涨一万粉」变成「这四个因子里先动哪个」，不负责替他选题。**

### 内容变现（有粉但不赚钱）

```
收入 = 粉丝数 × 看到卖点的比例 × 咨询比例 × 成交比例 × 客单
```

**常见瓶颈（经验）**：多半不在粉丝数，而在**第二格**——他从来没在内容里说过自己卖什么。
判据：过去三十条里，有几条让人知道「你这儿能买到什么」？

## 门店 / 线下

### 客流与营业额

```
营业额 = 路过人数 × 进店率 × 成交率 × 客单价 × 天数
```

| 因子 | 怎么量（不用系统） | 动它靠什么 |
|---|---|---|
| 路过人数 | 挑三个时段各数十分钟 | 位置（多半是条件，不是问题） |
| 进店率 | 进来的 ÷ 路过的 | 门头、陈列、门口那一米 |
| 成交率 | 买单的 ÷ 进来的 | 接待、动线、价格标示 |
| 客单价 | 营业额 ÷ 单数 | 搭配、推荐 |

**常见误拆**：把「生意不好」直接归到「位置不好」。**位置多半是条件（改不了），把条件当问题解是无限消耗**——
先量进店率和成交率，那两个是能动的。

## 学一门技能 / 能力类（目标不是钱）

```
能不能做成这件事 = 练习次数 × 每次有没有反馈 × 反馈够不够快
```

**关键判据**：**没有反馈的练习是白练。** 所以这类目标的第一步几乎总是「去哪拿到反馈」，而不是「每天学两小时」。

**完成态怎么写**（这类最容易写成愿望）：不写「学会剪辑」，写「**到十一月底，我能独立剪完一条三分钟的片子并发出去**」——指得出东西。

⚠️ **健康、体重、心理状态类的目标不进这个库。** 见 SKILL.md〈什么时候明说不该用本技能〉。

## 招人 / 找合作

```
招到一个人 = 接触候选人数 × 愿意聊的比例 × 聊得拢的比例 × 愿意来的比例
```

**常见瓶颈（经验）**：在第一格和最后一格。中间两格通常没问题，
**而最后一格（愿意来）往往不是钱的问题，是他看不见这件事能长成什么样。**

## 库里没有：现场推三问

### 跟钱有关的

> **谁付钱 · 付几次 · 每次多少**

三问答完就是一个乘法式。答不出「谁」——那不是目标问题，是这件事还没有买家，**去 `/aikey-product` 先把卖什么定下来**。

### 跟钱无关的

> **谁来 · 来几次 · 每次留下什么**

「留下什么」那一格必须是**可指认的东西**（一条内容、一次回复、一个名字、一行数据），不能是「印象」「信任」这种量不出来的词。

### 推完自检三条（公理 2）

1. 每个因子**能单独量**吗
2. 每个因子**对应不一样的动作**吗
3. 乘回去**单位对得上**吗（别把月和年、人数和百分比混着乘）

三条都过，这个式子才能进关三。
