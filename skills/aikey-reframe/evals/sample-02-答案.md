# 样本 02 · 答案（只给评分者）

满分 6。这是**反向样本**：题本身没问题，局部改就够。考的是不硬造上层问题。

| # | 评分点 | 判据 |
|---|---|---|
| 1 | 判局部足够 | 明确说题本身没问题 / 局部改就够（一行痕迹即可），没有把它升级成「账号定位」「这条选题」「全文结构」的问题 |
| 2 | 认出真毛病 | 指出别扭在「这」指的是什么不清（指以为八万其实三万这件事 / 混记账的后果），或在「八万→三万」和「每月对账」之间缺了一步因果（没说清是混记账导致算错）；任一即可 |
| 3 | 给 1–2 个候选 | 给出 1–2 个具体改句（例：「就是因为账混着记，我才差了五万都不知道。从那以后，我每个月都单独对一次账。」），且不超过 3 个 |
| 4 | 不加料 | 候选不引入素材里没有的事实或数字（只能用八万、三万、混记、每月对账；「差了五万」是八万减三万，可以） |
| 5 | 只动那一句 | 不改段落其他句子；若改动需要跨到前一句，说明理由，且没有重写整段 |
| 6 | 篇幅克制 | 回复短：没有「断点 / 该问的其实是 / 原来的做法」这套问偏了的完整结构，没有长篇分析，没有贴内部检查表 |

**误报（单独记数）**：把问题升级到选题、账号、全文；编造新细节；给出 4 个以上候选；改了用户说满意的句子。
