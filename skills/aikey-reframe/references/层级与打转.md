# 层级与打转：毛病在哪一层、是哪种转法、问偏了怎么重新问

> `aikey-reframe` 第一步用的内部材料。交付时用他的话讲结论，「层」「打转类型」这些词不出现在回复里。

## 一、四层，从上往下数

一条内容、一套流程、一个技能、一门生意，凡是能动手改的，都能拆成这四层。层越高，动一下牵扯越多；**可层高不等于该往高处改**：几块之间彼此牵连很弱时，就地改最省事。单纯的知识问答用不上这张表。

| 层 | 管的事 | 怎么查 |
|---|---|---|
| **前提** | 这事该不该照这个路子做 | 事实、因果、够不够得着、是目的还是手段，四条挨个过；做法能不能整个拿掉，留给第二步 |
| **目标与尺子** | 想要什么、什么样算好 | 顺着「为了什么」往上追；手里没尺子，先立一份能比对的好样子（他满意过的那版、一组固定样本） |
| **规矩与分工** | 允许干什么、谁管哪段、谁能看到什么、怎么递交 | 规矩相互顶牛，先排座次，别再写同义的新规矩；越修越乱，转去重新拆分工（第三节） |
| **参数** | 多少、多强、怎么措辞 | 不拆，只拧；拧到最大最小，看结论翻不翻 |

**怎么用**：在同一层拧来拧去不见效（最常见的是不停换措辞、不停加规矩）→ 上一层去找。毛病也经常卡在两层交界处，而不是某一层内部。

## 二、六种常见的转法

先认出这回是哪种。表里找不到的，自己用一句话说出它怎么来的，并照着表的几列补齐：现象、往哪改、搜什么词、在哪层。新冒出来的种类只在这次回复里讲，不往表里添。

| 转法 | 现象 | 往哪改 | 搜什么词 | 层 |
|---|---|---|---|---|
| **换词不换底** | 几版改的是同一个位置，或者都把同一件事当成理所当然 | 揪出那个共同的底；题没问题就退回还管用的旧版，题偏了就重新问 | 双环学习、隐含假设、问题框定 | 前提 |
| **手里没尺子** | 结论随着最后一句意见来回晃 | 先把评判标准定下，再一条条比 | 评分量表、评价标准、决策准则 | 目标与尺子 |
| **一块扛了别人的活** | 就这一块，怎么调都别扭 | 把各块的职责重新分一遍（第三节第 3 条） | 职责分离、信息层级 | 规矩与分工 |
| **越补越乱** | 补丁越来越多，彼此冲突，效果原地踏步 | 照第三节走 | 杠杆点、规则膨胀、系统重构 | 规矩与分工，再往上看尺子 |
| **指标替了目标** | 数字达标了，可不是他想要的东西 | 分开真目标和替它站岗的那个数，分开入口和重心 | 代理指标、古德哈特定律、目标置换 | 目标与尺子 |
| **只治表面** | 改在毛病露头的地方，不是毛病长出来的地方 | 顺着流程往上游找源头那一步 | 根因分析、五个为什么 | 规矩与分工（上下游） |

认出种类后，想想别的行当有没有对付这类问题的成熟办法：

- **有把握**：直说办法，并讲清它和眼前这件事哪里对得上、哪里可能水土不服；
- **没把握**：不硬套，但起码点出这是哪类问题，留两个可搜的词。

跨行借办法，得机制对得上：眼前的对象、关系、限制，在那边对应什么；哪一处不同会让借来的办法失灵。名字相近、比喻好看、听着高级，都不构成借的理由。

> 不少人跳不出来，只是不知道自己撞上的这类问题，早就有人专门研究过。把它归类本身，就是这次交付的一部分。

## 三、越补越乱：缺的不是下一条规矩

在修一套东西（规矩、流程、技能、分工）时，下面四种迹象见到两种，就别再打补丁：

- 补得越来越勤，一次比一次大；
- 新补丁开始跟老规矩冲突；
- 同一类错误换了个样子又冒出来；
- 补完一轮，效果没有起色。

接下来按顺序往上摸：

1. **尺子**：有没有一份能比对的好样子或固定样本，能判断改完到底是不是变好了？要达成的结果本身定准了吗？没尺子，就先造尺子，别的往后放。
2. **规矩排座次**：顶牛的规矩分个先后，靠前的不过关，靠后的就不作数；分工能兜住的规矩直接删。
3. **从哪里拆**：找头一个挤成一团的地方——
   - 材料：原始证据、推测、已经敲定的结论、要交的成品，是不是堆在一处；
   - 次序：先判哪样、后判哪样，有没有讲清；
   - 分段与递交：每段递给下一段什么、凭什么放行、出了错退回哪段；
   - 谁来干：让同一个人、同一个上下文干，会不会坏了这一步的本意（典型的是自己给自己挑错）；只有会坏事，才换一个隔离的执行者；
   - 变动快慢：常改的和几乎不动的有没有分开放，动一处会不会扯到别处。

拆完要能看出实实在在的好转才值得拆；拆得太细，递交的成本会把好处吃光。原本打算加的那条补丁要是还有用，就塞进对应的层里（比如变成验收的一项），不再另起一条。

## 四、往外扩：是不是漏了哪层关系

需要扩大视野时，四个方向各看一眼，只收**不收进来就解释不了、改不动眼前结果**的东西。同一个部门、同一个话题，不足以成为收进来的理由。

| 方向 | 看什么 |
|---|---|
| 往上 | 更大的那套流程和最终结果，给眼前这件事设了什么限 |
| 往下 | 哪几个小环节、小判断合起来造成了现在这样 |
| 前后 | 前面要备好什么、这一步产出什么、后面谁接、反馈怎么回来 |
| 人 | 谁供料、谁拍板、谁兜后果、谁两眼一抹黑 |

往上要逐层走：每收进一层，记下它改变了哪样（解释、目标、原因、方案、风险、下手的层、验收）；到了某一层什么都不改变、或者证据撑不住，就记下停在这儿和为什么。**刚摸到一层有用的就收工不行，为了凑层数编一层出来也不行。**

彼此牵连弱、后果能撤回、验收各管各、不碍整体目标 → 就地改基本就够。

## 五、题问偏了：五种重新问法

断点算不算数，跟新答案能不能赢过旧答案没关系。一个断点可以同时属于好几种，办法可以叠着用。

| 种类 | 长什么样 | 怎么重新问 | 层 |
|---|---|---|---|
| **前提塌了** | 事实、因果、够不够得着、目的还是手段，某一条不成立 | 点出那一条，按真实的因果重新发问 | 前提 |
| **做法在养着问题** | 这招已经用过，问题照旧甚至更重；或者这招和问题互相供养 | 别再「同一招加大剂量」，去改这招所在的规矩或关系，换一招性质不同的；也不是简单反着来 | 规矩与分工 |
| **题现在没法答** | 拿不出评判标准、几种答案各有道理、答案悬在一个没人知道的事实上 | 先补标准或那个事实，或者拿一次小测试替掉嘴仗 | 目标与尺子 |
| **卡在手段上** | 问的是工具怎么用，真正要的在更上面 | 升到他真正想要的那层重新问 | 目标与尺子 |
| **圈子画小了** | 毛病是上下游或者几方之间的关系造出来的 | 照第四节往外扩 | 规矩与分工 |

判「做法在养着问题」要有凭据：试过之后问题还在或加重，或者能把那个互相供养的圈指出来。光凭「推到极端会变糟」不能这么判。

新题要讲清：原来把什么错当成了什么，这回动了哪条关系，它怎样说通了旧问法说不通的事实、开出了什么新路。换个框架不一定要先找到更大的系统，同一层里也能换。

## 六、前面都试过还卡着，再挑一个角度

这些只用来找方向，不改他要的结果，也不替他整篇重写。挑对路的那个，不用挨个过。

| 角度 | 什么时候拿出来 | 怎么做 |
|---|---|---|
| **把两头拆开满足** | 这头好了那头就坏 | 写清两个互相拉扯的要求，再看能不能错开：不同时段各管一头、不同的人或部分各管一头、什么条件下优先哪头、整体顾一头局部顾另一头 |
| **先当它已经砸了** | 方案挑不出毛病，心里却没底 | 设想照做以后黄了，列出最像的两三个原因，回头看现在的安排有没有挡住 |
| **换一种摆法** | 一直用嘴说，越聊越糊 | 画成流程、排成表、算成数，或者换个计量单位（每单几分钟、每周几小时）重新看 |
| **推倒重来想一遍** | 已经改了很多轮、补丁一大堆 | 他要的结果不动，假设今天白手起家、现有安排一概不算，会怎么搭；拿来跟现状比，先改差得最远的那一处。它跟减法不同：减法一次只掂量一个做法，这里是把现有做法统统放下 |
| **换几个侧面**（可选） | 只看到了一面 | 从分工流程、人的需求与本事、利益与权力、意义与认同四面各说一句，看哪一面一直没人提；不沾边的跳过 |

## 七、什么时候收手

下面任何一条出现，那个方向就不再往外伸：

- 再上一层就要动他想要的结果，或者动他已经定下的定位和取舍；
- 再扩、再换框架，解释、目标、原因、方案、风险、下手的层、验收都已经不会变；
- 新加进来的只是更多背景、更虚的说法，左右不了眼下的判断；
- 再往下推就得靠没有根据的假设：把未知原样留着，决定性的缺口只问最要紧的那一个；
- 上层的影响看到了，可这一轮能动的范围，只够把它记成约束、风险或者要交接的事。

收手时把依据和还不知道的东西记下，**别说自己找到了一劳永逸的最高层**。他再喊一次，本身不是继续往上扩的理由；可复查时真发现了漏掉的东西，也不受上次收手结论的约束。

## 八、做法从哪里长出来（形成答案时顺手用，不另设关卡）

- **减法**凭的是两个问题：这个东西不要了，它干的活还能不能有人干；拿掉一个手段，就回到它原本服务的目的，另找手段。
- **长出做法**：从已经确认的结果和非有不可的条件起步，一项一项想他能干什么；把要搭配着干的动作连成一整条路；再给每条路找出那个一变就得换做法的要害条件。
- **用多大力气**跟题对不对是两码事：默认认真解；他明说「能用就行」，或者再找下去的代价明显比问题本身还大，才给将就的办法；要放着不管，得有「管不管结果都一样」的根据；让问题从此不再出现的那种改动，归到减法里。
- **只求搞懂的题**：好结果是把相关事实讲通、接住反例、分清哪些是原因，还要说出什么证据能推翻这个解释，不硬塞行动方案。交付前先把候选结论放一边，拿原始事实和他真正关心的东西倒查一遍有没有漏掉的解释；查出动摇结论的反例，回第一步 1.3 重判。
