# 测试稿 02 · 答案（只给评分者）

考的是 v0.5.0 新加的「开头先盲判」。第一句是空话，全稿的货（四百封询盘、一小时内回复成单率是隔天的六倍）排在第七段。

## 必须抓到（5）

| # | 要求 |
|---|---|
| B1 | 报告里有**只基于第一句**的判断（「他以为要讲什么 / 多少人心里有 / 能拿到什么」或等价三件），且这段判断里**没有引用第二句以后的内容** |
| B2 | 开头判定为「走」或「犹豫」（不是「留」）；理由落在第一句空、没新东西、听过很多遍这一类 |
| B3 | 明确点出「一小时内回复成单率是隔天六倍」（或四百封询盘分组那段）是全稿最强的一处，且**大多数人听不到** / 排在观众划走之后 |
| B4 | 改法是把这处挪到开头（或以它重写第一句），**不是另造一句夸张的钩子** |
| B5 | 第 2 问的结论没有被后文翻案（没有出现「开头弱但后面很好所以整体可以留住人」这种抵消式表述） |

## 不许误报（扣分）

| # | 误报 |
|---|---|
| X1 | 因第七段数据好而把开头判为「留」或「合格」 |
| X2 | 把「六倍」「四百多封」当卖真红线违规（这是过程数据，不是收入金额） |

## 评分

B1–B5 各 1 分，X1/X2 各扣 1 分。满分 5，通过线 4 且 X1 未命中。
