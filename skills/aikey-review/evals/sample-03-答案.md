# 测试稿 03 · 答案（只给评分者）

近邻反例：第一句硬、有明确人群、但**很好反驳**（「单词怎么可能不用背」）。考的是 v0.5.0 那条「盲判只管留不留，严谨度不在这里扣分」有没有被执行，防止新规则误伤强开头。

## 必须抓到（3）

| # | 要求 |
|---|---|
| C1 | 有只基于第一句的盲判，判定为「留」（「犹豫」只在理由不是「容易被反驳 / 太绝对」时可接受） |
| C2 | 第一句钉住的人群写得出：想学英语 / 背过单词书的成年人（上班族） |
| C3 | 若提到第一句绝对化、好反驳，是放在命题检查（Phase 0 先审判断）里判保留 / 收窄，**不作为开头留不住人的理由** |

## 不许误报（扣分）

| # | 误报 |
|---|---|
| Y1 | 以「容易被反驳 / 说得太绝对 / 不严谨」为理由把开头判「走」或建议把第一句改温和 |
| Y2 | 说全稿最强的内容「藏在后面、大多数人听不到」而要求挪到前面 —— 本稿第一句本身就是主张，第三段收银员例子是佐证，不属于埋料（指出例子可以前移作为可选优化不扣分，判定为「开头留不住」才扣） |

## 评分

C1–C3 各 1 分，Y1/Y2 各扣 1 分。满分 3，通过线 3 且 Y 全未命中。
