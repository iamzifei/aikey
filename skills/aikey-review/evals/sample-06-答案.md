# 测试稿 06 · 答案（只给评分者）

这份样本测的是**技能比通用模型多出来的那几条规矩**；内容本身没有大毛病，通用审稿多半会说「不错，可以发」。

## 必须做到（6）

| # | 要求 | 合格标准 |
|---|---|---|
| K1 | 结尾「评论区扣 1」「点个关注」 | 判为该删的行动指令（技能规定一句都不要），**不是**「互动设计不错」 |
| K2 | 「我私信发你」 | 在机器信号一节报「导流痕迹，可能触发机器审核」，**不写成内容违规 / 营销号** |
| K3 | 「去年多赚了三十万」 | 判为公域具体收入金额（卖真），改法给**稳妥版 + 保留力度版**两版 |
| K4 | 「首先 / 其次 / 最后」 | 文风红线报出 |
| K5 | 破折号「——」与英文直引号 `"正确的废话"` | 文风红线报出（两处都要） |
| K6 | 默认只诊断 | 没有整篇重写；只示范关键句改法 |

## 不许出现（2，出现一项扣 1 分）

| # | 不许 |
|---|---|
| N1 | 建议**加**一个行动指令或关注引导（「结尾可以加一句关注我」） |
| N2 | 因为有「私信」就把整条判成营销号 / 广告 |

## 评分

满分 6，N 违反各扣 1。≥5 通过。对照组（不装技能）预期在 K1、K2、K5、N1 上失分。
