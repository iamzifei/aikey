# 反应预测：这条发出去，谁会停、会做什么、来的是什么人

> 给执行者看的。对用户只说人话：不说「关系类型」「把握等级」，说「这句只有做外贸的会停」「这句会有人来吵」。
> 本文件只回答「观众会怎么反应」，不回答「说得对不对」—— 后者归 SKILL.md Phase 0 的命题五问。两件事分开报，不许用一件抵消另一件。
> 带走什么、会做什么的细分类型不在这里重复，深挖交 `/aikey-resonate`。本文件管的是**顺序、范围和代价**。

---

## 一、一条总纪律：只算观众走得到的部分

观众是顺着听的。稿子里的每样好东西，都要先问一句：**听到这里的人还剩多少？**

- 开头判「走」：后面的例子、金句、方法**一律不计入**评论、收藏、转发、关注的预测。它们照样要在报告里点名，用途是「挪到前面」，不是「证明这条会火」
- 开头判「只留一部分人」：后面的预测只对留下的那部分人做，写明是谁
- 开头判「误会题目」：跟「走」一样处理 —— 留下来的只是冲着那个被讲窄了的题来的少数人，后文的东西只能对他们算
- 判断依据要写到句子：「第 7 句的数据会让人收藏」—— 同时写清听到第 7 句的是哪些人。**六行里只要有一行引了开头之后的句子，那一行就必须带上「但多数人听不到这里」或「只对留下的 X 成立」**，不许在这一段默认人都还在、到了别的段落才说这里掉人

🟡 推断。如果错，最可能错在长图文和可以拖进度条的长视频：观众会跳读，「顺着听」的假设变弱。这两种形态下这一条降为提醒，不作硬约束。

## 二、开头判定的五种结果（扩 Phase 0 的留 / 犹豫 / 走）

盲读三行写完，结果落进下面其中一种。对用户**不说档位名**，直接说那句话：

| 结果 | 怎么认出来 | 对用户说 |
|---|---|---|
| 留 | 陌生人也看得出这事跟自己有关、听下去能拿到东西 | 「大多数刷到的人有理由听下去，因为……」 |
| 只留一部分人 | 已经关心这件事的人会留，别人没理由 | 「只有本来就在想这件事的 X 会留下」 |
| 误会题目 | 后文讲的事跟很多人有关，开头却包成了术语、行业内部话题、或一个没人问过的问题 | 「开头让人以为你在讲 A，其实你讲的是 B，而 B 才是很多人关心的」 |
| 走 | 看不出跟自己有什么关系，也看不出听下去能拿到什么 | 「开头没给人留下来的理由，后面的 X 大多数人听不到」 |
| 不判 | 用户没给真实的标题 / 封面 / 第一句 | 「你没给开头，我不从正文里挑一句替你当开头，这一项先不判」 |

**「误会题目」是最值得单独抓的一种**：它不是开头弱，是开头**把一个大题讲成了小题**。改法几乎总是把后文里那个跟普通人有关的后果提到第一句。

**冲突句式不等于留人。** 一句话吵得再凶，观众得先在乎被吵的那个东西。开头是「X 根本不是你以为的那样」时，先问：观众本来对 X 有看法吗？X 变了，他的钱、他的处境、他对自己的看法会跟着变吗？都没有，就是在跟一个没人在乎的东西吵。

## 三、这事跟谁有关：范围 · 强度 · 显露

第 1 问「这题有人需要吗」要落到三个量上，每个都写出来：

**范围**，从窄到宽挑一个：
- 得有专门的知识或从业经历才懂（例：跨境收款的税务口径）
- 一个清楚的角色，大家处境一样（例：一个人做外贸的）
- 几种不同的人认得出同一件事（例：老板和员工都吃过「开会没结论」的亏）
- 普通人日常就会反复碰上（例：手机上的订阅忘了取消）

**强度**：
- 淡：看完有点意思，生活不会因此变
- 中：能让他解释得更清楚、选得更好、心里舒服一点
- 强：碰到他手上正在做的事、他的钱、他的风险、他是谁

**显露**：这层关系**第几句**才被观众认出来？
- 第一句就认得出 → 好
- 要听到中段才明白「原来在说我」→ 跟「误会题目」同病，报给第 2 问
- 用的是宽泛标签（「打工人」「宝妈」）但没有他认得出的具体处境 → 标签不等于关系

🔴 不许写「人人都会感兴趣」。写不出具体是谁、为什么跟他有关，就是没找到。

## 四、六种反应，分开判（Phase 4 报告里一段）

按观众碰到的先后排。每种只写一行：**推它的是哪句原文 · 拦它的是什么 · 把握**。

| 反应 | 问的是 |
|---|---|
| 停下 | 第一眼凭什么不划走 |
| 听完 | 后面还有什么值得等；哪一段会开始掉人（精细的交 `/aikey-flow`） |
| 评论 | 有没有让人想表态、反驳、补一句「我也是」的地方；门槛低不低 |
| 收藏 | 以后还会回来用它吗：步骤、清单、判断标准、一次记不住的密度 |
| 转发 | 他会拿它去帮谁、替自己说什么、在群里当什么谈资 |
| 关注 | 看完会不会觉得「这人以后还能给我同类的东西」 |

**把握**只用三种说法：「原文里有明摆着的」·「有迹象，要看拍出来的效果」·「看不出，缺画面 / 数据 / 账号信息」。
**不预测播放量**，也不给总分。六种反应之间不互推：吵得凶不代表会收藏，收藏多不代表会关注。

片面归因、说得绝对、立了对面，这些**都要当成推力或阻力来记**，写清它推的是哪一种、拦的是谁。它们对不对，是 Phase 0 的事。

## 五、来的会是谁，离你卖的东西多远

读 `config` 里的账号定位与产品。**没有也照判，不先追问**，把缺的标成「未知」。

先说流量主要是哪几类人：看热闹的 · 被戳中的 · 同行 · 可能买你东西的人 · 已经在用你东西的人 · 只来吵架的人。

再给一个距离：

- **近**：这条碰的就是你的产品替人解决的那件事，来的是会买的人
- **中**：这条展示了相关的本事，还差一步才连到具体需求
- **远**：人主要是冲着热闹、吵架、或一个跟你生意无关的身份来的
- **未知**：config 里没有产品或账号定位

距离「远」不是扣分项。它只提醒一件事：这条的数据好看，不等于生意会来。和第 9 问「凭什么是你」一起看。

## 六、每条改法都要写代价

改动清单里每一条，写满四格：

```
改哪里：（原句）
想换来：（六种反应里的哪一种变强）
要付出：（哪种反应变弱，或者哪类人会被推开）
不能动的：（这条稿里已经立住、改的时候必须留下的东西）
```

常见的交换，供对照（最后必须落到这条稿的具体句子上，不许只贴表）：

- **把话说死**：更容易停、更容易吵、更容易被复述；中间派和被说到的人会走
- **只讲一个原因**：好懂、有确定感、好站队；经历复杂的人不认
- **立一个对面的人群**：评论和转发上去；那群人和他们身边的买家一起走
- **放一个具体数字**：更抓眼、更好记；数字没有参照时等于没放
- **讲深讲全**：收藏和关注上去；听完率和泛人群掉
- **给步骤**：收藏和「会买的人」对得更准；情绪和讨论变少
- **亮身份和成果**：停和关注上去，也更可信；观众更容易觉得「那是你，我学不来」
- **说得更泛**：能碰到的人变多、转发变多；真正的目标客户认不出这是在说他

**和 Phase 0 命题检查的接缝**：命题判「收窄」时，改法里要写出收窄会拿走哪种反应。例如把「成年人背单词没用」收窄成「每天只有半小时的人别从单词书开始」，站得更稳，也更少人想来吵。**这个代价说给作者听，由他选**，不替他选。

## 七、改法的先后

1. 开头判「走」或「误会题目」→ 第一条永远是：把后面最强、跟最多人有关的那句提到开头。其它都排后
2. 开头能留住人之后，再修中段最明显的掉人点
3. 已经立住的关系、收获、会让人动手的那句，改的时候先保住
4. config 里有商业目标 → 同等条件下保「会买的人」；没有 → 把「传得更远 / 攒关注 / 离生意更近」三个方向分开写，让作者挑

最多给三条。
