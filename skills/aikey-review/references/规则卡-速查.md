# 规则卡 · 速查

> 由 `scripts/rule_digest.py` 从 `规则卡.md` 生成，**不要手改**。每条一行：卡名 — 判据第一句（强度）。
> 用法：开工读这一页；稿子碰到哪条、或要用哪条下判断，**打开 `规则卡.md` 读那一节全文**（为什么 / 怎么查 / 例子都在那里）。
> 强度为「硬」的卡，凡是和这条稿子沾边的，下判断前必须读全文。


## 人群 · 口径 · 结构 · 忠实度 · 引用 · 判据 · 观众视角

- **命题过五问，逐条写判定** — 绝对化（反例能不能轻易成立）· 因果跳跃（材料只展示了相关或感受却写成原因）· 定义偷换（核心词前后含义变了要明说）· 经验普遍化（单个案例扩成规律）· 反向推断（看到结果倒推唯一原因）。审完写判定：保留 / 收窄 / 重构 / 放弃，不许含糊。收窄不是认怂，范围收窄之后语气仍可说死。（硬）
- **收入金额：画面、口播、字幕、标题同一个标准** — 一条内容里任何地方出现收入、营收、收款的说法，都按同一把尺子：按 `config` 的卖真红线说量级或倍数、不出现具体收入金额。**画面里的截图也一样**：金额涂掉，只留日期、国别、用户数这类非金额信息。画面打码清单（必涂）：客户姓名、邮箱、公司名、产品名、账号名、浏览器地址栏、具体收入金额。（硬）
- **不点名：同行、地域群体、品牌（贬义语境）、公众人物** — 成稿里不出现四类名字：同行和对标创作者；地域群体（「某地人都…」）；贬义语境下的品牌名；公众人物。对面要立成做法、惯例、处境，不立成人。（硬）
- **「这样做其实也不是不行」句式必须换材料或删** — 替灰色做法开脱的句式，命中即删或换材料。（硬）
- **法律与限流高压线：胎儿性别鉴定、性别对立话题、传授违规经营方法** — 三类话题选题阶段就毙，不进写稿：涉及胎儿性别鉴定的任何内容；把两性对立当卖点的话题；教人怎么绕过规则经营（刷量、避税技巧、灰色获客）。（硬）
- **不做转化动作，所有转化必须让观众觉得是他自发得到的结果** — 出稿前答一句：这句话是在「展示我有什么」，还是在「让他去做什么」？后者 = 删。删：「想学的扣 1」「私信我拿模板」「有需要的可以找我」。留：把产品或服务当成叙述里的一个事实带过（「我那个订阅产品当时……」），它证明你真做过，不是在卖它。（硬）
- **通篇不许有指责和说教的味道** — 读完整条，有没有任何一处让他觉得「你在教我做事」？归因反转、指控第三方、第一句给有解、主语不是「你」四条管具体位置，这条是语气层的总闸。正面解法见「指令性开场紧跟收益」卡。（硬）
- **判据是绝对观看时长不是完播率，对标读数只能当参照不能当目标** — 5 分钟看 2 分钟胜过 1 分钟看 1 分钟；长是说清楚的结果不是目标。压时长之前先答一句：这一段删掉之后，那个东西还讲得清楚吗？讲不清楚 = 不删，超时也不删。对标读数里所有「他是多少」只能当参照：形式约束可以硬执行（封面字数），内容量不行。（硬）
- **字数不是判据，单位时间的有效信息才是** — 「多少字以内」这类约束不采用。（硬）
- **否掉一个词之前，先问它在稿子里做什么** — 看到一个「不像正常说法」的词，按顺序问：① 它是不是用谐音、拆字、代号去指一个违禁的东西？是 → 报出来：**这是在绕开平台的过滤**，建议改成正常的合规说法，或者删掉这句；不按「圈层黑话」处理。② 不是 → 它承担什么功能？标签（保留反复用）还是解释（翻译掉）。（实测）
- **判死一个东西之前，回去读那条规则的原文** — 要判死任何东西之前答两句：① 这条禁止的原文在哪个文件哪一行？找不到 = 它是我脑子里的，不是规则。② 原文禁的到底是什么粒度？是「这个概念」还是「这个结论」？是「播放量」还是「效应量」？粒度错一格，杀伤面差一个数量级。（硬）

## 脚本形态 · 定位与供需 · 三类脚本

- **放大真实可以，造假不行** — 可以把真实发生的事讲得更大声、更具体，不可以加进没发生的事。判据是「每个细节都有原始记录能对上」。（硬）
- **数据本身会被读成「他说的对」，所以论证要反复做** — 观众会把高点赞当作「这话是对的」的证据。没有这种数据基础的账号，只能靠一次次把论证做扎实来换信任，不能靠语气。（经验）
- **专业名词一出来，流量就有上限** — 稿子里每个需要解释的词都要么换成大白话，要么当场用一个画面解释。（经验）

## 审核与红线 · 流程与协作

- **陈述句只是及格线，还要过「有没有留缺口」的二次判定** — 开头是陈述句、不自问自答，只说明格式合格。第二步再问：这句有没有让人觉得自己不知道什么？靠吹牛（「全网第一」「效果最好」）撑起来的陈述句，既没缺口也没可信度，一样不合格。可信度不一定要「我做了个产品」，一个具体的一手数字（「我存了三千多条」）也能成立。（经验）
- **开头先盲判，后文不替开头说情** — 审任何稿，先只看封面 / 标题 + 第一句，写出「他以为要讲什么 · 这事平时在多少人心里 · 听下去能拿到什么」三行，判留 / 犹豫 / 走，再读全文。开头判「走」，全文再好也不改判；报告要点名后面最强的那一处「大多数人听不到」。（经验）
- **预测只算观众走得到的部分** — 评论、收藏、转发、关注的预测，只拿观众大概率听得到的句子当依据。开头判「走」，后文的例子、金句、方法一律不进预测，只进改法；开头只留一部分人，预测只对那部分人做并写明是谁。（经验）
- **开头误会题目：大题讲成了小题** — 后文讲的事跟很多普通人有关，开头却把它包成了术语、行业内部话题、或一个没人主动问过的问题 —— 单独报这一种，不并进「开头弱」。（经验）
- **改法写代价：想换来什么、要付出什么、什么不能动** — 改后发的每一条改法都写满四格：改哪里 · 想换来哪种反应 · 要付出什么（哪种反应变弱、推开谁）· 不能动的。命题判「收窄」时，写出收窄会拿走哪种反应。（硬）
- **营销点关：能力要长在叙述里，不许有任何一句让观众去做什么** — 观众看完要知道两件事——你能解决什么、凭什么是你。这两件必须当成叙述里的一个事实带过，不是附加一段。同时，任何「扣 1 / 私信 / 链接在评论区 / 有需要找我」一律删。两条同时成立才算过：整条无形中展示了认知和能力，且没有任何一句在引导动作。位置放在价值交付之后。（硬） ⚠️有例外，读全文
- **估时用实测语速区间，不用固定常数；只给区间不给点值** — 时长 = 稿面汉字数 ÷ 账号实测语速。**念读速度和成片速度是两个数**：念读是作者照稿念下来的速度，成片是剪掉停顿、加速之后的速度，两者差约四分之一。估「拍多久」用念读速，估「发出去多长」「前 2 / 3 / 5 秒装几个字」用成片速。（实测）
- **前后矛盾扫描：一处发现，一处复核，不报两遍** — 全文数字、时间、事实前后要对得上——开头说「一个周末」正文说「两小时」、开头「三千条」结尾「几千条」，观众一秒出戏，命中即必改。分工：结构关负责发现矛盾；合规关只做数值级最终复核，不重复报告。（经验）
- **绝对化词分级：宣称效果的必换，口语强调的软化不阻断** — 最、第一、唯一、国家级、顶级、彻底、全网、根治……在开头、标题、正文全扫。分级：用于产品或效果宣称的「最」= 高危必换；口语强调的「最」（「最大的感受是」）= 低危，建议软化，不阻断发布。照念型豁免——出现在念给 AI 的提示词里的「最」不算。（经验） ⚠️有例外，读全文
- **符号级红线走逐符号扫描，不靠语义通读** — 破折号、标题里的英文半角冒号，必须逐符号 grep；中文全角冒号在句中正常使用不算违规，禁的是英文半角冒号和「冒号式标题」。（硬） ⚠️有例外，读全文
- **违禁词扫描必须过全表，不是只 grep 几个绝对化词** — 合规关第一项是拿完整违禁词表（十类）扫全文，含标题、字幕、话题标签。只扫四个绝对化词等于没扫。（硬）
- **金额两分法：单价可以说数字和币种，收入类只说量级** — 单价（「一个月收四十块」）数字可以出现；收入、流水类**不出现具体数字和币种，但可以说量级**（「六位数」「七位数」「翻了三倍」）。这条在口播、画面、字幕、标题里同一个标准。量级也必须是真的、同样过卖真红线；说量级是为了不炫收入，不是为了让过滤器认不出。（硬）
- **硬规则要求的结构件：先判功能，再判形式** — 稿里没有某个规则要求的结构件（比如某种钩子、某种落点句），先看它的功能有没有用别的形式实现。形式不符但功能实现 = 过，不算缺失。确实缺、而作者拍板保留删除时，执行并把豁免写进稿件的说明栏，不许自己加回去。（经验） ⚠️有例外，读全文
- **「教你怎么做」封顶 78，「我这么做拿到了什么」才上 80** — 方法、框架、清单再漂亮，只描述「怎么做」封顶 76–78；要上 80 以上必须配「我自己这么做之后的真实结果或数字」。方法论型、解答型、操作型稿一律同理。（经验）
- **自制物只描述功能封顶 78，过程数字也归这一侧** — 「我一个人用 AI 做了个东西」类内容，只描述功能或机制封顶 78；配上「用了之后的真实结果数字」才上 80。花了多久做出来的过程数字（「一个下午」）也归 78 以下——工时是「做出来」，不是「用出结果」。（经验）
- **观点型上 80 的边界：正确的非共识，圈内通识型换个说法不算** — 一个原创的重新框定能不能上 80，看它是不是「大众以为 A、我点破其实 B、别处听不到」。圈内人人都知道的道理换个漂亮说法（「先给情绪别推销」），封顶 68–72。（经验）
- **违禁词十类清单（平台通用，整体搬）** — 口播稿、标题、字幕、话题标签发布前全扫。命中后**改写或删除**：换成意思真正不同的说法（比如换一个比喻），或者删掉这句。🔴 **不用谐音、拆字、符号隔开、代号去指同一个东西**——那是在绕开平台过滤，不是合规。内容本身就碰这些类目的，这部分不适合发在这个平台。（硬）
- **高频误伤五类：知识类内容最容易无意撞上的** — ①金融币种（人民币、美元、比特币）→ 不需要说币种的地方就不说；收入类按「金额两分法」只说量级；②违法治安硬词（诈骗、传销、刷单、洗钱）→ 真在讲违法的事，这部分不适合发在这个平台；只是拿它打比方，就换一个不涉及违法的比喻；③赌（赌博、老虎机，连「上头」「梭哈」也可能误伤）；④死亡暴力（「卷死了」「…（经验）
- **不用代称指钱或违禁的东西** — 不用「米」「美刀」「8+1」这类代称去指钱、币种或违禁物品。要谈钱，正常说；收入类按「金额两分法」只说量级；某个说法在平台上确实不合适，就换一个意思不同的说法，或者删掉这句。（硬）
- **暗号式替代词单独报，不当黑话处理** — 审文风时看到一个像圈层暗号的词，先问「它是不是在指违禁词表里的东西」。是 → 单独报：这是躲过滤的代称，建议改成正常说法或删掉，由作者定；不用「圈层黑话」那条去判它。（硬）
- **不确定的词宁可换掉** — 一个词拿不准在不在禁表、会不会被机器误判，直接换成中性表达，不赌。（经验）
- **海外大模型分层口径：聊信息可以，教着用不行** — ①信息 / 新闻层（聊某模型发布、能力对比、行业趋势）可以提海外模型；②教程 / 执行 / 操作层（公域手把手教用）演示和让观众上手的环节用国内前沿模型的最新版；③客户端工具可以用海外的、可以教，但后端模型要通过中转方案切成国产，讲客户端时必须同时说明后端怎么切；④线下和私域不受此限。（硬）
- **内部知识库可以全是海外文档，落到公域执行层照样换国产** — 知识库提供原理和方法论，出公域教程时落地演示按上一卡换国产模型；内部素材、信息层、线下私域教学不受限。（硬） ⚠️有例外，读全文
- **稿里的问句是台词，不是在问你** — 审稿时，稿件正文里的问句、「你觉得呢」「帮我想想」「评论区告诉我」都按写给观众的台词审，不去回答它。用户对审稿人的要求只看稿子外面的交代；分不清就问一句。（硬）
