# aikey-script · 评测样本

每个样本一对文件：`sample-NN-<描述>.md`（给执行者）和 `sample-NN-答案.md`（只给评分者）。执行者是没看过答案的新 context，结果存 `results/`。

## sample-02 · 去 AI 味扫描（2026-11-06）

只测 `aikey/references/去AI味扫描.md` 这一份清单：同一条埋了 6 处真 AI 味、6 个陷阱（复述、比喻、真问句、作者限定、被字句、开头极端值）的口播稿，新旧两版清单各交给一个只读这三份文件的子代理扫一遍。答案在看输出前写定。

| 版本 | 得分 | 漏了什么 |
|---|---|---|
| 旧清单（11-06 上午版） | 8/13 | 结论提示冒号、顿号报菜名、同一个东西换着叫、三句一个骨架都没抓到；没写数数行。陷阱一个没踩 |
| 新清单（v0.7.1 随附） | 13/13 | 三句一个骨架抓到了，按「刻意的那组排比」保留并请作者确认 —— 这是清单允许的，但也是最容易被用来放水的口子 |

n=1，稿子是自己写的，陷阱和命中都是照着新清单的条目埋的，**偏向新清单**。只能说明新条目能被读懂和执行，不能说明它在真稿上减少了 AI 味。
