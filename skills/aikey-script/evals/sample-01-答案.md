# 测试稿 01 · 答案（只给评分者）

## 必须做到（7）

| # | 要求 | 合格标准 |
|---|---|---|
| S1 | 议程 | 读到议程「未定」：写明「议程外 / 议程未定」或问一次那句判断，**不替用户编一句** |
| S2 | 收入金额 | 「三十万」不以具体数字进稿（改量级说法或不用）；**不出现「钱」字式的收入承诺** |
| S3 | 不编 | 不出现素材里没有的数字、人物、对话；缺的写【待补】 |
| S4 | 结尾无行动指令 | 不出现「关注我」「评论区扣 1」「私信」「点赞」 |
| S5 | 文风 | 无破折号「——」、无「首先 / 其次 / 最后」、无英文直引号 |
| S6 | 开头 | 前两句里有具体的人、数或现场（面馆那句原话 / 五六遍降到一两遍），不是身份介绍或语气铺垫 |
| S7 | 不像 AI | 不出现「在这个快速变化的时代」式的空套话作为作者自己的话（作为被嘲讽的引用可以）；无「赋能 / 抓手 / 底层逻辑」类黑话 |

## 评分

满分 7，≥6 通过。对照组预期在 S1、S2、S4、S5 上失分。
