# 人物故事与自我介绍

> 写「我是谁」的个人故事、自我介绍、人设立号那一条稿时读。也适用于替别人（客户、学员、嘉宾）挖故事。
> 来源：一位短视频 IP 操盘手的线下课，他在课上拆了十几个替客户立人设的真实案例。下面是从案例里归纳出的做法，**案例本身不进成稿，也不点名出处**。
> 与 SKILL.md 的关系：结构（五段磨难转机）和口径（推理叙事，不是苦情叙事）照 SKILL.md；本文管的是**结构之前那一步 —— 讲哪条线、用什么立住这个人**。

## 一句话

**先挖出一个身份或细节 → 让它代表一群人 → 用一连串小事和处理方式把人立住。**
故事好不好看，看的是经历有多稀缺；结构只是帮你上手。

---

## 一、四条判据（按顺序过）

### 1. 故事不是讲「我多牛」，是替一群人讲

- **判据**：写完问一句 —— 这条故事代表的是哪一群人？答得出一个具体人群（「个子小的女生」「借钱周游世界把房贷滚成窟窿的人」），才算立住。只答得出「我」，就是在讲我多牛。
- **为什么**：「我多牛」的故事观众早就看腻了，而且只能换来敬佩，敬佩一次翻车就崩。代表一群人，观众看到的是自己。
- **怎么改**：从经历里找一个**会让一群人对号入座的细节**，拉成一条贯穿全片的线。
- **案例形状**（去标识）：一位客户原稿通篇讲自己多成功。操盘手挖出她「个子小」，拉出一条线：小学、初中、高中、大学、工作，一路因为个子小被瞧不起，最后一步步破除。故事从「我厉害」变成「小个子女生在这个社会上遇到的所有阻碍，我是怎么过来的」—— 小个子女生、再往外女生、再往外所有被小看的人，都能对号入座。
- 🔴 **那群人要是平台上的大多数**：先问「这群人每天刷视频时，脑子里本来就有这件事吗」。房贷和工资带来的焦虑、对未来没底、怕被 AI 取代，是大众处境；「想法很多、一直想自己干」是小众画像，数量少，共鸣起不来。优先选你**自己真实经历过**的那种大众处境。（作者自己的一条自我介绍稿实测：第一版选了小众画像，被判「不是大众情绪」，人群整段重写。）
- **强度**：硬。

### 2. 先找身份，再找定位：身份本身就是差异

- **判据**：在同行里找一个**只有他有、而同行没有**的身份切面 —— 年龄、出身、上一份职业、一段特殊经历。它往往比「他做什么行业」更能立人。
- **为什么**：同一个行业里，行业标签人人都有；身份切面才是别人抄不走的。找对了，连买家都会变成同类人。
- **案例形状**（去标识）：
  - 一位卖农产品的中年老板，原本做产品知识普及，没起色。聊天里挖出他当过很多年兵，做了一条讲当兵经历的人设故事，把「军人」这个人格立住，之后买家几乎都是退伍军人。
  - 一位做农村自建房的老板，同行年纪都偏大、只发图文。他是 90 后、敢出镜口播，就用「年轻、敢出镜」这个身份做切口，粉丝不算多，获客却比粉丝多得多的同行还好。
  - 一位律师，专业内容几乎没改，只把出镜身份从「像律师」换成「专门针对老公的受害者妻子」，用剧情演出来，流量才起来。原话大意：流量来自身份的转变，不是内容。
- **怎么查**：把稿子里的「我是做 X 的」遮住，只看剩下的部分，还认不认得出这个人？认不出 = 只有行业没有身份。
- **强度**：经验。

### 3. 人设靠「处理方式」立，不靠自我评价

- **判据**：不写「我是一个大气 / 靠谱 / 讲义气的人」。写一件具体的小冲突，**还原冲突细节 + 讲出我当时怎么处理的**，让观众自己得出这个评价。
- **为什么**：自我评价没人信；处理方式是证据。观众最愿意看的处理方式：随手帮忙、坚持底线、伸张正义、敢作敢当、当面回馈，以及「过度慷慨」（把本来是交易的事变成一份礼物）。
- **案例形状**（去标识）：
  - 一位餐饮店老板上完课回去拍的第一条：店里停电，全场免单，拍得很粗糙，数据却很好。后来遇到跑单，建议继续拍，把「大气」这个人设用一件件事叠实。
  - 一位大哥在公共场所被人当面说胖，当场拿手机录下自己怎么回应，这条火了。
- **怎么做**：生活里遇到烦心事、争吵、麻烦，当下就记下来（手机备忘录、跟 AI 说一遍），或者直接录自己。**素材最大的问题不是没技巧，是不知道什么能成为内容。**
- **强度**：经验。

### 4. 一个人可以拆成很多条线

- **判据**：一个人的故事不是只能讲一遍。按「人」拆（写父母、写伴侣、写一个朋友），按「物」拆（一辆车、一套房），按「关系」拆（后来谁支持了我）。
- **为什么**：人设不是一条视频立起来的，是一系列事件累积出来的。
- **强度**：经验。

### 5. 弱点要和你现在卖的东西是一条线

- **判据**：故事里承认的那个弱点，应该正是你现在的业务在解决的问题。写完问一句：这个弱点和我现在做的产品、立的人设、卖的东西，是同一件事吗？
- **为什么**：只是性格缺点（自控力差、脾气急）的弱点，讲完观众记住的是一个人，和你的业务无关；和业务同一条线的弱点，讲完观众记住的是「这个人为什么懂这件事」—— 弱点就是他的资格。
- **怎么改**：从业务倒推 —— 你现在帮人解决什么问题？你自己当年是不是也栽在这个问题上？把那几次栽跟头串起来，就是主线。
- **强度**：经验（作者自己的一条自我介绍稿实测：第一版落点是「自控力扛不住诱惑」，被判和业务无关，整段重写）。
- **另一种合法做法**：弱点直接讲大众情绪（焦虑很正常、人生本来就起起伏伏），业务靠**一处反差**单独带出来（例：「按理说我是程序员，头一批被 AI 冲击的就是我们，结果反而是 AI 让我头一回做成了一门生意」）。两者不必是同一件事，但反差那一句必须有。（同一条稿的第三版，作者本人改定。）

## 二、素材怎么挖（在 SKILL.md Phase 2 第 3 项之前做）

1. **列十件事**：「影响我、改变我人生的十件事」，按板块分 —— 工作 / 感情 / 原生家庭或朋友。正面负面都写，写三十件也行。
2. **给每件事打权重**：你自己心里有一把尺子，分得出哪件更重。挑权重最高的几件串成一条线，这条线就是主线。**先有主线，再套结构**；不要拿模板去找事。
3. **聊出来，不是想出来**：替别人写，先跟他聊。替自己写，找朋友喝点酒、开着录音聊人生，或者打开 AI 跟它聊（「我要写我自己的故事，你从哪几个维度问我」），最后从录音或对话里把事记出来。
4. **每件事追到画面**：时间、地点、数字、当时说的一句话（与 SKILL.md「曲折事件五问」同一标准）。

## 三、结构（套在主线上）

五段交替：**开场 → 磨难 → 转机 → 磨难 → 转机 → 感悟**。

- **开场**三选一：个人成就 / 个人经历 / 个人磨难。自我介绍最常用「成就开场」—— 先给结果，再倒回去讲怎么来的。
- **磨难**题材：一意孤行、恶霸欺压、至亲背叛、强权干涉、过河拆桥、奸人所害。
- **转机**题材：因祸得福、伙伴加入、贵人相助、发现漏洞、破釜沉舟、通关密码、意外之喜。
- 另一种流行的故事句式：「第一杯酒敬……第二杯酒敬……第三杯酒敬……」，每杯一个人生节点。句式只是壳，**火不火看经历本身的稀缺度**。

🔴 **每一段磨难都要落在「当时我是怎么想的、哪里想错了」**（SKILL.md 推理叙事口径）。磨难转机的起伏是用来留人的，推理是用来让观众带走东西的，两样都要有。

## 四、写完自检

| 问题 | 答不上来 = |
|---|---|
| 这条代表的是哪一群人？ | 还在讲「我多牛」，回判据 1 |
| 遮住行业，还认得出这个人吗？ | 没有身份切面，回判据 2 |
| 有没有一处「我是一个 X 的人」的自我评价？ | 换成一件具体的事 + 处理方式，回判据 3 |
| 每段磨难里，观众能带走一次判断吗？ | 滑向苦情了，回 SKILL.md 故事型口径 |
| 弱点和我现在卖的东西是一条线吗？ | 只是性格缺点，回判据 5 |
| 每个数字、每件事都是真的吗？ | 🔴 卖真红线，挖不到就问，不编 |
