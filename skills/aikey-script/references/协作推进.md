# 协作推进：怎么和作者一起把稿子往前推

> 谁用：`aikey-script` 的 Phase 0–4（定型、拉弹药、逐段共创）。`aikey-concept`、`aikey-drama` 的共创环节同样适用。
> 管的是**怎么问、怎么记、怎么往前走**；写什么、怎么写仍按本技能正文和规则卡。
> 这些都不是关卡：每一条都只决定「下一句说什么」，不决定「能不能继续」。

## 一 · 素材分四栏记，交稿时分得开

拉弹药时，每一条素材在装配表里标一栏：

| 栏 | 是什么 | 进稿时怎么写 |
|---|---|---|
| **原话** | 作者或当事人亲口说的，带出处（哪次聊天、哪条评论） | 可以直接引用 |
| **事实** | 可以核对的：数字、日期、发生过的事 | 照写，数字一个不改 |
| **推断** | 你从材料里推出来的（「他这么做多半是因为……」） | 不能写成作者的话；要用就写成「我猜」「很可能」，或者先问他 |
| **设想** | 还没发生、希望发生的（「下个月要开第二家」） | 写成计划：「打算」「如果……就……」，不能写成已经做到 |

最常见的错：把推断写成原话，把设想写成结果。交稿前扫一遍：稿里每一句「我做到了」「他说」都要能在前两栏里找到。

## 二 · 先给判断，再只问一个会改变走向的问题

1. **能判断就先判断**：材料够定型、够写第一段，就先拿出来，不为了「走流程」而提问。
2. **要问，只问一个**，而且问之前自检：**他答 A 和答 B，稿子会不会走向两个不同的样子？** 不会 → 这个问题不问，你自己按最合理的默认往下写，在稿里标出你选了哪个默认。
3. **问题要能用一句口语回答**，不要把「讲给谁、讲什么、为什么、怎么收」塞进一个问号。
4. **说清为什么问**：「你这个答案决定开头用结果还是用现场」。

## 三 · 他怎么回，你怎么接

| 他的回应 | 你怎么接 |
|---|---|
| **说得很短**（「就那样」「差不多吧」） | 当成压缩过的经验：结合上下文给一个你的理解，让他改，不要求他补一大段 |
| **说「不知道」「你定」** | 替他推两三个方向，各说一句代价（「A 更好拍但会撞上周那条；B 更新但要补一个数」），问哪一个不对。**不把原问题换个说法再问一遍** |
| **举了别人的例子**（「像某某那样」） | 拎出这个例子在**这条稿里**意味着什么（节奏？口气？结构？），继续写他的稿；不去模仿那个人的全部 |
| **说法很抽象**（「要有温度一点」） | 给两三种具体的理解（「是多放现场细节，还是多用『我』少用『你』」），说你倾向哪个，让他挑 |
| **纠正方向** | 说清你要改的是哪一层（选题？结构？某一段？措辞？），只改那一层和受它影响的部分，**不从第一步重来** |
| **质疑你没看全局** | 停下逐段细抠，先用三五句话把整条讲清楚：讲给谁、那一个点、怎么展开、怎么收，再回到他最在意的那处 |

谁定什么也分清：**他定**的是立场、愿意承认的事、愿意承担的代价、哪句话他不会这么说；**你承担**的是结构、候选、素材归类、措辞初稿。不让他替你做结构设计。

## 四 · 每到一个节点，交一小段工作稿

形成新判断或方向变了的时候，用三四句话交代现状，不每轮贴全表：

> 已经定下来的：……　我倾向：……　因此下一步动：……　唯一还悬着、答案会让方向变的：……

他一眼能看出你理解到哪了，也能一句话纠正。不用每次都四栏齐全。

## 五 · 交稿前多做两个检查

- **换人检查**：把稿里作者的名字、身份换成同行任何一个人，这条还成立吗？还成立 → 这条只有道理没有他，回去找只有他才有的那件事（他做过的、他看见的、他吃过的亏）。
- **真实选择**：故事型和经历型的稿，里面有没有一个**真的岔路**（他本来可以选另一条，选了这条才有后面的事）？没有岔路的经历只是流水账；岔路必须是真发生过的，不能为了好看编一个。

## 不做

- 不把内部的四栏表、工作模型整张贴给他看，除非他要。
- 不为了显得周全，每轮都问「要不要继续」。
- 不替他认领一个他没说过的身份或立场（「你作为一个……的人」）。
