# 规则卡 · 速查

> 由 `scripts/rule_digest.py` 从 `规则卡.md` 生成，**不要手改**。每条一行：卡名 — 判据第一句（强度）。
> 用法：开工读这一页；稿子碰到哪条、或要用哪条下判断，**打开 `规则卡.md` 读那一节全文**（为什么 / 怎么查 / 例子都在那里）。

## 人群 · 口径 · 结构 · 忠实度 · 引用 · 判据 · 观众视角

- **不要用单一职业窄化人群：先散后聚** — 先铺开人群举例，再收到一个共性。全篇只对一种职业说话 = 窄化。（硬）
- **杠杆、优势这类概念要泛化到全部人群** — 「代码这个杠杆」只覆盖程序员，「你的专业本事」覆盖所有人。（经验）
- **术语有两种用途，处理方式相反** — 解释用的术语 → 翻译成人话；标签用的术语 → 保留并反复用。（硬）
- **标签词第一次出现时翻译一次，之后直接用** — 翻译是为了被听懂，重复是为了被记住和转述。先听懂，再记住。（经验）
- **指人的词按「这一句在说谁」选，不按你的行业选** — 每一句问一遍：这句在讲机制，还是在讲一个具体行业的具体场景？讲机制 → 用最泛的那个词，全篇统一；讲具体场景 → 切换成那个行业的词，但只切那一段。一条稿跨了线上线下时，主词用最泛的，不混用。（硬）
- **具体的大数字胜过模糊的长时间** — 「我被问了十年」换成「光这个月就被问了十几次」。（经验）
- **数字要说，「钱」字不能说** — 排名、名次直接说；收入类金额说量级（六位数 / 七位数），不说具体数和币种；单价可以说具体数；替代词用「商业 / 年入 / 结果 / 规模」。（硬）
- **数字必须紧跟方式** — 只有数字 = 简历；数字 + 方式（怎么做到的）= 论据。（硬）
- **资历放最后是兑现，放开头是背书** — 先给方法，最后说「我就是这么来的」是兑现；开头植入要用「承认对方是对的」那一招。（经验）
- **升级「代价」只能升级他已经在承受的那个，而且不进前 5 秒** — 允许：他已经在承受的代价（「这半年拍了六十条粉丝还是四位数」），那是他本来就有的动机。禁止：我替他设想的后果（「再这样下去你就废了」），它同时触「第一句不给你惨」「不让他先认领不体面身份」「不许说教」三条。位置：一律 5 秒之后。（硬）
- **结尾要三段：收束、动作、回扣** — 只收束会戛然而止。动作给获得感，回扣给情绪，回扣要呼应开头。（经验）
- **三项并列里，把最重的那个用「最关键的是」拎出来** — 平铺的并列观众只记住最后一个，加一句「最关键的是」等于替他指定记哪一个。（经验）
- **机制不能断在「变了」，必须走到「所以对你有什么后果」** — 每写完一个机制答一句「所以呢？」答不出 = 这条机制还断着，观众拿不走。（硬）
- **替观众说的那句内心话要用直接引语** — ❌「你会觉得很有收获」 ✅「你就会发现，我靠，原来还可以这样」。脏字只用最轻那一档，且只用在替观众说内心话的位置。（经验）
- **理论段是全篇最容易出现缺口空档的地方** — 把理论段单独拎出来，它里面有没有至少一个缺口？没有就在报书名之前先抛一个悬念。（实测）
- **系列前一条的关键词，否定式用法允许而且更强** — 同系列前一条的关键词在本条是禁词，但「不是 X，是 Y」的否定式用法允许；肯定式仍然禁止。（经验）
- **「你自己的路径」这条，AI 稿和本人口述稿判据不同** — AI 稿必须有一件他身上发生过的具体事，缺了就是「谁都能拍的稿」；本人口述稿不强制具体事件，他的语言指纹和推理顺序本身就抄不走。（经验）
- **数量承诺可以下两次** — 第一组讲完观众注意力预算用完，立刻再报一个数量 = 续期。（经验）
- **动作门槛要降到荒谬，并配触发器** — 「每天写作」没人做，「每天写十个字」有人做；小到荒谬本身就是记忆点。配一个触发器（送完孩子顺手走两圈），启动成本为零。（经验）
- **反馈可以从结果层降到动作层** — 「不是数据好不好，是写没写」。判断型自我反馈（好不好）无效，事实型自我反馈（做没做）有效。（经验）
- **用古语当金句** — 古语比自造金句有质感而且不油，因为它不是你的话。（经验）
- **给时间尺度** — 「坚持一年两年，超过八成的人」，让抽象的坚持变成可想象的期限。（经验）
- **当代名人引用只在确实说过且能核实时用，且不能是唯一支撑** — 经典著作作骨，必须查过原文；当代名人只在确实说过且能核实时用，不能是唯一支撑；流传的名言不用。（经验）
- **收尾用「资格条件」，不喊行动** — 「如果你已经有 A、也有 B，但被 C 困住，先判断自己适不适合。」把筛选权交回观众。（经验）
- **末段把话题从战术升格成定义** — 「X 从来不是一种价格策略，它是……的加总。」前面讲战术，最后一句抬层级，收藏发生在这一句。（经验）
- **引用是给已有判断找根，不是给新判断** — 引出了他没说过的东西 = 替他思考。（经验）
- **名字念不顺的不进口播，但只限一份名单** — 只排除名单上那几个名字（只用观点不报名）；名单之外的经典作者一律指名道姓，按固定句式写，年份放最前。（硬）
- **引用四段的第三段，「某学科是从这本书来的」优先于「这个人一辈子研究什么」** — 第三段目标是让没听过这个人的观众知道他为什么值得听。有「某学科基本从这本书来」这种说法时优先用它，更短更重更好念；没有才退回「一辈子研究什么」。（经验）
- **落点写成论证，不写成断言** — 把落点那句话遮住，观众能不能自己说出来？能 = 论证；不能 = 断言，改。（硬）
- **「误区」只做选题来源，不做文案内容** — 稿子里有没有一句话在替观众下「这是个误区」的结论？有 = 删，只留拆解本身。「原来我以前想错了」必须由他自己说。（硬）
- **每一个抽象结论后面，必须跟一个观众自己能验的具体场景** — 逐句扫：这句是抽象结论吗？是 → 下一句有没有一个他自己能验的场景？没有 = 补，或删掉那句抽象的。科普三件套：先说那句绕的（机制原话）→ 立刻翻译 → 给一个他身上就有的场景（不是行业案例，是他昨天干过的事）。（硬）
- **画面里的一切都是信息点，口播精简、画面密集** — 穿搭、桌搭、背景、墙上的东西、手里拿的、音效，全是信息点。线性通道（口播）要精简，并行通道（画面）要密集。（经验）
- **升华的判据是那句话能不能被证伪** — 能 = 真升华；不能 = 假大空。升华指向后果，不指向意义。结尾的祝福和鼓励（「希望每个人都能……」「加油」）一并删；用回开头那个词的回扣不算升华，别误删（见 `aikey/references/去AI味扫描.md` 第二层）。（经验） ⚠️有例外，读全文

## 口播标准 · 出稿循环 · 时长与语速 · 钩子

- **纯口播正文连续成篇，不做逐句分镜** — 正文从第一行到最后一行能一口气念完，中间没有画面说明、镜头标注、分镜表格。真需要动作（手势、打大字、配图）的段落，单独列在正文之后的「需要处理的节点」表里，按行号索引。（硬）
- **一条只讲一个点，说透为止，不设时长上限** — 整条只围绕一个概念、一种认知偏差、或一个错误常识；讲多久由「这个点需要多长才能说透」决定，不是由目标秒数决定。信息装不下时先做删除测试（逐句假设删掉，逻辑、信息、节奏三样都没损失就删），压不动再调语速；绝不靠砍论证来缩时长。（硬） ⚠️有例外，读全文
- **最强的类比或金句往前放，不留作落点** — 全稿最有力的一句（主类比、翻转句）出现的位置，必须在平均播放时长能覆盖到的范围内；不能默认放在结尾「让人截图」。（实测）
- **例子必须能被看见，看不见就不是例子** — 读者能不能从这句话里看见一个具体的东西：一个数字、一个屏幕、一个动作、一个物件。看不见 = 这是概括不是例子。补救只能回原始记录挖最小可见物，不许凭想象补细节。（硬）
- **一个论点只出现一次，话头当场接完** — 抛出的话头必须在当段接完，不许隔几段再回来接。同一个论点想说第二次，说明第一次没说清，回去改第一次，不是加一遍。（硬）
- **转轴句必须是判决句，拍摄处理表标「一字不改」** — 把切口打开的那一句（「讲到这儿才是重点，这根本不是 X 的事」）必须写成可以独立成立的判决，不能写成可替换的转场；并在处理表里单列一行标「一字不改」。（实测）
- **承担对照功能的数字，处理表标「必须念出这个数」** — 凡是一个具体数字在做对照锚（「已经是第四个来源了」「三天对三个月」），处理表单列并标「必须说出这个数」。（实测）
- **表述强度可以推满，事实一个字不能动** — 可以推满的：情绪、动词、比喻、节奏；在真实区间里取最有力的说法；用最强案例不用平均案例；判断语气斩钉截铁。一个字不能动的：数字（金额、人数、时长、倍数）、亲身经历的有无、因果关系的强度、第三方的话、改变结论的限定词（「样本一个」「未验证」删不得）。（硬）
- **动笔前和出稿后，用观众身份各问三句** — 用观众的身份问，不用作者的身份问：①这条内容，我自己会不会被吸引住 ②我愿不愿意点进来看 ③看完我会不会想转给某个人，或想在评论区说点什么。三问各答一句，答不出的那一问就是这条的短板。（经验）
- **事实主张优先配证据画面，证据里的钱和第三方信息打码** — 涉及事实主张（做过什么、拿到什么结果、某个数字）时，能拍证据就不用嘴说：后台截图、录屏、实物、时间痕迹。三条合规：①一切金额数字打码或虚化 ②第三方的人名、头像、联系方式打码 ③演示类录屏遵守你配置里的合规口径。没有现成素材就在稿末列采集清单交作者补拍；宁用真素材，不用网图或 AI 生成的假证据。（硬）
- **正文按换气单元分行，手写行号，只标气口** — 一行 = 一个换气单元，不是一个句子也不是一个分镜。行号手写（`NN │ 正文`，两位右对齐），因为多数 markdown 渲染器不显示代码块行号，不手写就没法按行反馈。行尾只允许三种气口记号：`⏸` 停半拍、`⏸⏸` 停一拍（急刹车、金句前）、无 = 连着念。（硬）
- **每一版正文后面必须跟：迭代表、处理点、建议、好处、坏处；坏处不许空** — 每版四块：①迭代表（迭代的部分 / 是否采用 / 背后的原因 / 最终修改，原因要引反馈原话或实测数据）②需要处理的点（按行号，写「做什么」）③我的建议（明确给判断，不写「供参考」）④这一版的好处 + 坏处（好处具体到哪一行带来什么；坏处必须写，写不出坏处 = 还没审）。（硬）
- **一条稿一个文件，版本倒序，实际播出的那版永远排最上** — 文件骨架固定顺序：frontmatter → 去重（闸门，写之前就该过）→ 引文出处 → 标题与封面 → 全文（版本倒序：播出版 → 口述版 → 当前文案版 → 作废版）→ 素材采集清单 → 发布后数据 → 口述时请留意。（硬）
- **作废版本只留四样，其余一律删** — 作废版只保留：一句作废理由 + 正文代码块 + 迭代表 + 好处坏处。不保留：自检、备选钩子、落点句落地表、缺口分布表、处理点、压时长清单。（实测）
- **frontmatter 是稿子的身份证，几个字段缺一不算填齐** — 类型（含结构类型：概念型 / 论证型 / 清单型 / 故事型）· 时长（写区间，见语速卡）· 核心概念 · 理论点 · 封面大字 · 作品标题 · 作品描述 · 话题标签 · 主类比 · 落点句两版（认知版内部推理用；情绪版对外用）· 落点（观众最终带走的那个判断，和「核心概念」不是一回事：概念是工…（硬）
- **时长展示一律写「N 分 NN 秒」，秒数只留在计算注里** — 不足 60 秒才直接写秒；对照表、坏处栏、数据表里的时长同样适用。`183s` 这种写法不用。（硬）
- **语速用自己的实测区间，不用通用值；念读速和成片速分开** — 估时用「稿面汉字 ÷ 账号实测语速」，而且分清两个速度：**念读速度**（作者照稿念下来）和**成片速度**（剪掉停顿、加速之后）。估「拍多久」用念读速，估「发出去多长」和「前 2 / 3 / 5 秒装得下多少字」用成片速（平台的跳出率、5 秒完播、观看趋势全在成片时间轴上）。（实测）
- **~~实拍比稿面长约两成，估时要乘上去~~（2026-11-06 废弃）** — **不再单独乘 1.2**。改用上一张卡的两个速度：「拍多久」直接用念读速算，「发出去多长」用成片速算。（废弃）
- **每版代码块之后先跟「缺口分布表」，秒数必须算出来** — 表列：位置（行号）/ 秒数（用成片速算，未知时取保守值）/ 缺口（观众心里那个没被回答的问句）/ 手法（给结果不给过程 · 给矛盾不给解释 · 给问题不给答案 · 给反常不给理由）/ 兑现在哪一行（一次只还一层）/ 下一个缺口从哪来（接力 = 上一行的答案长出来的；另起 = 并列，要改）。（硬）
- **落点句落地表：情绪版落在哪几行，要写出来** — 每版正文后一张表：①情绪版落点句 + 缺口落在第几行第几秒 ②「我因此做错了什么」的动作落在哪 ③代价落在哪 ④现有解法的挂点落在哪。每格填原文和行号。（硬）
- **坏处之后跟「压时长清单」，并列出不许切的行** — 表列：切什么（行号）/ 省多少秒（成片速）/ 代价。同时列出 ⛔ 不许切的行及理由。（硬）
- **验收方式是作者把整稿念一遍，不是扫一眼；他说满意就停** — 出稿循环固定为：出整稿 → 作者复述一遍给反馈（哪儿别扭、哪儿念不顺、哪儿不像他说话）→ 按反馈出下一版整稿 → 再复述 → 直到他说满意。他说满意就停，不在之后再补「不过我觉得还可以再……」。（硬）
- **每一版都给完整整稿，不推倒重写，改动说明放正文后面** — ①每版给整稿，不只给改动段落——他念的是整篇，给零件听不出接缝顺不顺 ②不许每版推倒重写，他没提意见的部分默认已过，保住 ③这版改了什么、为什么，写在正文后面，不放前面挡住稿子。（硬）
- **复述时卡壳、改口、下意识换词的地方就是问题，主动问「哪几句念卡了」** — 即使作者没明说，复述时卡壳、改口、换词的位置一律当问题处理；每次收反馈主动加一句「哪几句念的时候卡了」。（硬）
- **口述稿原样留档，差异表默认口述版更好，但「改措辞」类例外** — 口述回来第一件事：原样留档，一个字不改，只在旁边标红线命中。然后做差异表（AI 稿写的 / 他口述时说的 / 类型 / 说明什么），类型只用五个：加 / 删 / 改措辞 / 换结构 / 调顺序。（实测）
- **口述删掉的结构件只列出来问，不许自己加回；批准后当场落正文并验证** — 他删掉的如果是硬规则要求的结构件（作业、边界、路径、跨行业场景），列出来问，写清「不加会违反哪条、代价是什么」，不许自己加回。他批准加回的，当场写进正文（不是写进建议栏），然后搜原句确认在。（硬）
- **引权威引到人名 + 书名 + 章节，禁止模糊的「古人」叙事** — 要引就引到可核的层级；查不到精确出处时去查，不许降级成「两千年前的人就这么干」这类模糊说法。陌生人名配一句身份（「那个国家最有名的修辞老师」）来过具象度，不是把名字删掉。稿末出处表逐条可核，推断级必须标出来。（硬）
- **引文三态不混用，自己的推论不挂在作者名下** — 外文原话留在后台做核实和存档，成稿里不出现；进成稿的是中文译文，译的时候只翻不加（原作者没给的案例和结论不能顺手补上去）；为了念得顺而压缩改写过的，在稿里标「意译」。每条引用给：书名 · 作者 · 年份 · 原文段 · 与稿里哪一行对应，并标明直译 / 转述 / 意译。（硬）
- **译名与页码纪律：不自行音译，不猜页码** — 外国人名用什么中文写法，按这个顺序找：他本人用过的中文名 → 正式出版的中译本怎么印 → 权威机构怎么称呼；几个写法都通行就把另一个也写上；一个都查不到就直接写外文名并说明，自己拼一个音译不算数。引页码要带是哪一版，版本不确定就只引到章，页码不猜。（硬） ⚠️有例外，读全文
- **选哪本书，写一行理由给下一条内容看** — 五维评分之后写一行结果，尤其是「机制匹配」那一维（例：机制匹配 3 / 5，某理论同题材但机制匹配 1，已淘汰）。（经验）
- **定义句写成三个短句，不写一个长定语** — 给定义时拆成并列短句（「说得出来。整理得出来。传得给别人。」），不写「你说得出来、整理得出来、而且能传给别人的那种」。（实测）
- **列举不用写满，判断句才要写死；给作者留临场加东西的余地** — 列举类内容写两三项就够，作者会自己补同类项且补得对；判断句必须写死，作者不会临场造判断。不要把每一句都焊死。（实测）
- **自我观察类开场直接写第一人称** — 讲自己观察到的现象时，写「我研究了半天……」不写「你研究了半天……」；作者念到这种句子一定会改成「我」。（实测）
- **稿件文件名序号按发布顺序排，不按创作顺序** — `序号_类型_关键词`，序号是发布顺序，日更时它就是排期表；类型对应你的内容配比分类；关键词能一眼认出是哪条即可。（经验）

## 脚本形态 · 定位与供需 · 三类脚本

- **手里有什么材料，就选什么形态，不反过来硬凑** — 先盘点这条能用的真实材料（干货点几个、真事几段、有没有可演的对话、有没有正在进行的处境），再从形态菜单里挑一个「填得满」的。形态有难度分级：低难度的只要有干货就能填；高难度的必须有真实案例或完整经历。材料撑不起高难度形态，就降级到低难度形态，不为了「更有感染力」去凑一个没材料的形态。（经验）
- **形态 · 连珠问答（低难度）** — 干货多但每条都撑不起一条视频时用。把每个知识点压成「一句观众原话的问题 + 一句直接回答」，连续堆 6 到 12 组，快切。每组必须单独成立：划到任何一秒进来的人都能拿走一个完整信息。问题用观众的说法，不用行话。（经验）
- **形态 · 逐个宣判（低难度）** — 观众面对一堆工具、做法、说法不会选时用。连续 5 到 8 组「对象 → 一句判断 → 一句具体原因」，节奏短促。原因必须落到具体事实（「它把数据传到境外」），不许是「不太行」这种评价词。只宣判自己真用过、真核过的对象。（硬）
- **形态 · 演一段拆一段（中等难度）** — 内容是某个对话场景或话术时用。先演一段真实或错误的对话（10 到 20 秒），切旁白拆「这一步该怎么说、怎么做」，再演下一段。旁白必须给出能原样照做的动作或原话，不给道理。（经验）
- **形态 · 站到弱势那边（低到中等难度）** — 内容里有真实的强弱对立（甲方对小供应商、卖方对不懂行的买方）时用。开头用弱势方的原话提问，呈现对立，讲述者明确站在弱势一方，给「方法 + 为什么 + 正确做法」。对立必须真实存在，方法必须能被验证。（经验）
- **形态 · 反派自述（低难度）** — 内容是行业内部套路时用。用「假如我要坑你，我会这么做」的视角逐条揭套路，最后翻回真实立场（「所以我不这么做」）。只揭套路，不点名任何个体或机构；结尾必须落回自己的真实做法。（硬）
- **形态 · 观点带案例阶梯（高难度）** — 有一个强观点，并且有真实案例（自己做过的优先）时用。强观点开场 → 递进举例 → 用故事做论据逐层加码 → 收回观点。故事只保留跟观点直接相关的细节。没有真实案例，一律降级到连珠问答或逐个宣判。（硬）
- **形态 · 半生速写（高难度）** — 有一段完整的个人经历可讲时用。极强钩子开场 → 出身起点 → 多个人生节点快切 → 最难那段放慢展开 → 一句感悟收尾。节点快切、低谷慢讲，节奏差本身就是情绪设计。每个细节都要真，数字守卖真口径。（硬）
- **形态 · 未完待续（中等难度）** — 还没有结果，但正在一个真实处境里时用。展示现在有多难（给具体数字）→ 为什么还没放弃 → 一句宣言 + 请观众见证。没有翻身结局，靠开放式结尾驱动追更。这是长线投入：后续必须真实更新进展，不管进展好坏。（硬）
- **记录类稿子有七种切口，先选一种再拍** — 真人实拍类内容按七个切口归类：挑战、生产过程、改造过程、日常、工作现场、还原一件事、体验一样东西。一条只占一个切口。（经验）
- **干货类稿子有七种切口** — 干货类内容按七个切口归类：避坑、省钱、谈资、追求更好、内幕、行业术语解释、解决一个具体问题。一条只占一个。（经验）
- **观点类稿子的三种起点和固定骨架** — 观点类稿子从三种东西起：一个热点、一件自己很共情的事、一件想吐槽的事。骨架固定为：说出争议点 → 表明自己的看法 → 三个论点必须逐条说出来（不许含糊成「原因很多」）→ 总结看法。（经验）
- **观点稿的四项自检** — 写完观点稿逐项过：① 每个论点够不够「一句话戳中」（具象、有画面、有共识），平、幼稚、堆道理都不算；② 讲给谁听说得清不清楚；③ 讲述者自己是不是真信、带不带情绪、有没有观点；④ 有没有滑成「给方法给方案」的干货稿。（经验） ⚠️有例外，读全文
- **观点稿最好用的两种立场** — 替一群人说出他们自己不好意思说的那句话，两种方向：他们一直想干却没干成的事，替他们找到能对外讲的原因；他们其实不想干的事，替他们找到拒绝的底气。（经验）
- **故事材料先分两桶：磨难和转机** — 挖个人故事时把材料分进两桶。磨难桶常见六种：一意孤行、被人欺压、亲近的人背叛、外力干涉、被过河拆桥、被人坑害。转机桶常见七种：因祸得福、有人加入、贵人出手、发现一个漏洞、破釜沉舟、找到关键窍门、意外之喜。五段结构是磨难和转机交替，最后落一句感悟。（经验）
- **故事开场三选一抛钩** — 故事型开场只从三种里选：一个成就、一段经历、一次磨难。三选一，不叠加。（经验）
- **挖曲折事件用五连问，追到特写级细节才算挖到** — 写故事型稿前，对一段「以为能成结果崩了」的事连问五句：后来做了什么、一开始为什么觉得有机会、哪一步出了问题、最直接的损失是什么、以为结束了之后有没有更糟的一下。每问都要追到时间、地点、数字、当时说的那句话。一条故事视频通常要两段以上这样的事交替。（经验）
- **挖故事要在放松状态下录音，不在写稿状态下回忆** — 个人经历先用放松的方式（闲聊、录音、不看提纲）把事讲一遍，之后再从录音里拎细节。不要一边写稿一边回忆。（经验）
- **故事靠具体细节累积，不靠形容词** — 故事线由「早上吃了什么、账户里剩多少、谁说了哪句话」这一级的细节堆出来，不用「艰难」「拼命」这类概括词。进阶结构参考三幕或五幕。（经验）
- **一条稿子只走一种：给方法的，或者给立场的** — 给解决方案、方法清单的是干货稿，服务「有用」；为一个立场辩护的是观点稿，服务「共鸣」。动笔前定一种，中途不串。干货稿另守「一条不超过七个点」和「每个点可照做」。（经验）
- **每条稿子先写下这一条的目的** — 账号的目的是一个，单条的目的可以不同：让人知道你的过去、你的专业、你的标签、你的实力、你的生活。动笔前写一句「这条让观众知道我什么」。写不出就别写。（经验）
- **实拍类四条通用原则** — ① 爆点前置：开头先放 2 到 4 个最有戏剧性的片段快切，再进正题；② 固定自我介绍：一句式，每条一样；③ 话术不写死：只定框架和目的，现场发挥，写出来照念一定假；④ 分段录制，对话感觉假了就按实际情况调整，不硬演。（经验）
- **说话对象要具体到一个人，用他的方式和情绪说** — 开录之前定三样：对谁说、用什么方式说、带什么情绪说。「对谁」要具体到一个想得起脸的人。（经验）
- **出镜紧张的机械解法** — 出镜恐惧不靠心理建设，靠机械动作：反复读稿、分段、重复录；眼神盯一个具体物（镜头旁贴个标记、放个水杯）；开录前大声喊几句或做口部操让声音打开；伸展一下、深呼吸、笑出声再录。（经验）

## 审核与红线 · 流程与协作

- **对标只借信号和骨架，战绩、观点、原文一概不借** — 可借：选题需求信号（收藏率高 = 有需求，做你自己的版本）、角度、结构、钩子形态。不可借：他的战绩 / 数据 / 产品说成你的；他的观点 / 经历当成你的亲身经验；搬原文或金句当原创。（硬）
- **成稿不出现任何具体创作者，可反查的指代也算** — 对外内容不出现任何特定创作者的名字，也不用「某博主的做法是……」这种能被反查的指代；对标只活在内部素材库和规则里。例外：行业公认的大厂和官方品牌（模型厂商、平台方）不在此限，本规则约束的是创作者个人和账号。（硬） ⚠️有例外，读全文
- **点名例外：为自己付过钱的东西承担立场，三条同时满足才放行** — ①真的付过钱，说得出付到哪一档；②稿里不提取对方任何方法论、案例、金句当自己的；③主动写明自己的利益相关。三条缺一不可。仍然禁止：替对方的具体观点辩护——只替品类被误解辩护，不替某个具体结论辩护。（硬） ⚠️有例外，读全文
- **对标逐字稿存两层：原件只用来核对原话，出稿只读提炼层** — 入库存「完整逐字稿」（原件，可回查提炼有没有失真）和「提炼稿」（元数据 + 结构提炼 + 去重判定 + 使用边界）两层。出稿只读提炼层；打开原件的唯一合法理由是核对某句原话，不是找灵感。（硬）
- **对标转写用本地语音识别，不用平台自动字幕；头部标未校对** — 一律本地转写；平台自动字幕会把关键术语整句转错，不可用。逐字稿头部必须写明转写工具、未校对、已知错字、引用前回听。音视频原件不进版本库，只有文字稿进。（实测）
- **出一条内容的六步调用顺序** — ①选题：素材层拉信号（本人爆款优先，对标旁证）+ 官方文档挖干货题，对照配比；②怎么做：方法论层定结构、钩子、时长、发布策略；③讲什么：本人素材填血肉，官方文档核事实；④怎么写：理论层做写作决策（好奇缺口、损失框架、一条一个点）；⑤怎么讲：风格参考层校准「讲给爸妈听」的比喻感，对照口播示范稿校准口语…（经验）
- **六步出稿流程：选题 → 出稿 → 自检 → 审核 → 复述 → 回流** — ①选题（立场层过三问 → 选题五步 → 去重闸门 + 姊妹条检查，产出落点句认知版和情绪版）；②出稿（结构 → 遣词 → 红线自检，按唯一模板产出文件）；③自检（细则表逐条打勾 + 缺口分布表算秒数）；④审核（逐关审，先过三个入口条件）；⑤复述（硬闸门）；⑥回流（拍完回填上传版 + 差异表 → 提炼…（硬）
- **复述是硬闸门：没有作者口头复述不许拍；优化只能从复述稿剪，不能从 AI 稿扩** — AI 稿写完之后，作者用自己的话复述一遍，复述稿才是拍摄稿。后续优化只能在复述稿上删，不能拿 AI 稿往里加。（硬）
- **三套正文结构是三个层级：外层容器六段，第五段内部按内容类型展开** — 外层容器固定六段（问题 → 承诺 → 重新定义 → 方法 → 为什么是它 → 收尾）；「为什么是它」那一段的内部展开按内容类型二选一：讲一个概念用概念型节拍，讲「我怎么走过来的」用亲历推理骨架，解答型用解答模板，纠偏一个熟概念用纠偏六段（具体问题 → 引出概念 → 大众怎么想 → 哪里不管用 → 理…（硬）
- **纠偏型准入两道闸门：有挂靠点，且观众能拿它去量一件你没提过的事** — 拆一个观众已经熟的概念时，先过两问：①这个概念在观众日常里有没有一个具体挂靠点；②纠偏之后长出来的那把尺子，观众能不能拿去量一件你没提过的事。答不出第二问 → 手上还是一个观点不是一把尺子。（硬）
- **观众视角横切：每写完一段，合上稿用「我」重读，写出他此刻那句内心话** — 每段写完做一次：合上稿子，以目标观众的身份重读，写出他此刻的一句内心话。写不出来 = 这段还没写完。全程站在大众观众的需求和认知上想「为什么点进来、为什么看下一个 5–10 秒」，避免任何指责和说教的感觉。（硬） ⚠️有例外，读全文
- **三种收获方向不同，四种冲动至少设计两样并写清落在哪几行** — 三种收获——「原来是这样」驱动收藏关注；「我就说是这样吧，别人还不信」驱动评论转发；「他替我说了」驱动转发（最强）。四种冲动——收藏（工具性）、转发（身份表达）、评论（有话要说）、关注（判断方式一致）。每条至少设计两样，写清是哪两样、落在哪几行；四样都没有 = 这条只是「看完了」。（硬）
- **引用是给观众已有的判断找根，不是给他一个新判断** — 默认要引经典出处，但引用的作用是支撑他已经隐约认同的判断；不许借引用偷偷补进一个他没有的新知识点。（经验）
- **通识不走引用纪律：任何一本同类教材都能找到的说法，直接讲不必点名** — 引用纪律管「引某本书的某个论断」；学科事实（教科书标准分法、公认术语）不是论断。判据：这个说法在任何一本同类教材里都能找到吗？能 = 通识，直接讲；只在某一本里 = 引用，走全套纪律。（经验）
- **长口播每讲完一层给一个观众能自己回答的问题，不召唤** — 长口播的「每层挂一个钩子」结构保留，但钩子是一个观众能自己回答的问题；「可以来找我 / 私信我 / 有需要的扣 1」一律不写。转化靠他答不出第二第三个问题自己意识到，不靠喊他。（硬）
- **限定词 vs 说死：两条相反的规则都在，出现时列出来问，不自己调和** — 「限定词要保留」和「判断要说死」在具体句子上会打架（「就是」改「多半是」）。目前未裁定，出现时把两个版本列出来让作者拍，不自己选。（经验）
- **去 AI 味和加人味是两步：先删不像人的，再主动加回像人的** — 去 AI 味只是删掉不像人的痕迹；之后还要主动加回口语噪声、内心话直接引语这类像人的东西。两步不能省一步。（经验）
- **姊妹条检查：表面症状相同、机制不同的那条是哪条，写进稿件头** — 选题时找出「症状相同但机制不同」的已有那条，写进新稿的元信息。痛点必须锚在两条机制真正分岔的那一刻，并把对方的关键词列为全文禁词。（硬）
- **缺真细节写【待补】，不填一个看起来合理的** — 价格、日期、原话、地点、时长这类细节，素材里没有就在稿里写【待补：……】继续往下写，交稿时全部列进素材采集清单。（硬）
- **别人的反应全在配合你的论点，就是编的信号** — 稿里出现的他人（客户、同事、家人、反对者）如果每一个反应都恰好推着你的论点走，回原始记录核对；核不到就标【待补】或删。（硬）
- **前面摆出来的每个误解，后面都要一个一个还上** — 纠偏型或对比型的稿，前面列了几条「大家以为……」，后面就要有几处对应的回应，一条不落；没回应的那条要么删，要么补。（经验）
- **回扣最有劲的一种：结尾用开头那个词，但它的意思已经变了** — 「结尾要三段」里的回扣，优先找开头用过的一个关键词，在结尾再说一次，让观众听出同一个词前后意思不一样了。（经验）
