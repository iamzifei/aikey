# aikey-title：标题与封面公式

先读 `aikey/references/家族公约.md`（读不到 → 明说「公约读不到，红线无法保证」并停下，**不凭记忆代替公约**），再读 `aikey/references/交互规范.md`（🔴 **不是读一遍就算**：收尾按 §四 三件套 —— Recap · Before/After · **下一步给编号选项**；缺信息按 §四 用**选择题**问，**一次只问一个**；不适用的情况见 §五），再读记忆 `{vault}/08-技能记忆/aikey-title/` + `_通用/`，理论出处见 `aikey/references/内容理论底座.md`（跟用户说话时只说人话，不说理论名）。结构清单与自测方法在 `references/标题结构库.md`。**注意它不是爆款公式库**——实证显示 12 种标题结构在两个风格不同的账号之间**没有一个跨源复现**，所谓通用公式不成立。（这说的是标题；口播开头另有一条实测最强的形态，见 `aikey-hook`。）

本技能内置判据在 `references/规则卡.md`（判据 / 为什么 / 怎么查 / 强度），开工前读一遍；`{vault}` 里有对应的规则文件时以 vault 为准、规则卡为底。

起标题本身不值钱，随便哪个模型都会。这个技能存在的理由只有三条：

1. **按这条内容本身的形状选结构**，不是套一个「最灵的公式」（因为不存在）
2. **过红线**——这是通用工具没有的那一层
3. **说清你为什么这么选**，让用户能判断你对不对

**每个标题都要说明用的哪个结构（S1–S12）和为什么适合这条内容。** 说不出来的，就是随手写的。

## 两种进入方式（先分清，输出形态不同）

| | **被用户直接调起** | **被写稿技能归口调用**（2026-08-23 加） |
|---|---|---|
| 手上有什么 | 一条稿或一个题 | **完整正文，且它还没定稿** |
| 输出 | 标题候选 + 结构编号 + 红线结论 | 同左，**外加一条：要不要动正文** |
| 控制权 | 在你这儿 | **在调用方那儿**，你给完结果就还回去 |

### 被调用时多做一件事：回推

**封面大字和前 2 秒是同一个决策的两个出口。**
封面写「别加功能」，开口第一句「别再往你那个产品上加功能了」——
这不是两件事。

所以被调用时，除了给标题，**还要判断一句：按这个标题，正文开头要不要改。**

- 要改 → 明说改哪一句、改成什么，交回调用方
- 不用改 → 也明说，让调用方知道你查过了

🔴 **这是引入调用的全部理由。** 线性接力做不到这件事：等接力发生时稿子已经冻结，
标题只能去迁就正文。**你被调用，就是为了能反过来说话。**

### 交给开头：三行卡（2026-10-10 加）

标题定了、接着要做开头（同一次调用里，或用户下一步去 `/aikey-hook`），**交三行，不交感觉**：

```
① 方向：这条押的是哪一句（一句话，就是选中的那个标题想让人认出的东西）
② 边界：稿子 / 片子里实际有的材料，开头不能超出它（第 3–5 档时贴原句）
③ 兑现：标题的承诺在正文第几句还上
```

**三处说同一件事，但不说同一句话**：
- 封面大字给**关键词**，标题给**完整的处境**，开口第一句给**一个具体场景或问题**
- 三处里有任意两处整句相同 → 改掉其中一处。整句重复等于观众在前 3 秒把同一句话读了两遍，白白占掉了留给缺口的位置

⚠️ 被调用时**不要**走完整的「先确认发哪个平台」问答——调用方已经知道平台。
直接产出，把问答省给用户。

## 标题从哪来（2026-08-23 加，前置于本技能的一切公式）

**在起标题之前先确认它是怎么来的。**

❌ 从爆款榜上摘一个改写 —— 那是抄结论，而且标题一样就没有新鲜感
✅ 从内容里**长出来**：常识 → 解释不了的现象 → 深理论 → 反常识判断 → **往上抬一层才是标题**

大切口三条判据，全过才算：
- [ ] 不懂这行的人也知道你在说什么
- [ ] 它是从本条内容的判断里长出来的，不是从别处摘的
- [ ] 单独拿出来仍然有缺口（他不知道你要说什么，但想知道）

⚠️ 只抬**一层**。抬两层就到人生哲理，那是空的。

→ 完整五步见 `aikey-topic/references/常识缺口法.md`

## 🔴 标题从哪来：从落点句，不从爆款榜（2026-08-26 加）

**先保留选题的未解问题与正文承诺。** 若上游按 `aikey-topic/references/问题探寻与共鸣.md` 得到具体的价值、去留、投入或可行性问题，可直接打磨，不要求出现情绪词。结构库是表达分类，不替代问题生成，也不证明某种表达有效。

**一种可用路线：落点句 ① 的情绪版，换个人称**（以下检查仅适用于这条路线）：

```
① 认知版   我的注意力每天都被外界安排        ← 认知词：注意力
                ↓ ★ 换情绪词（共鸣全在这一步）
① 情绪版   我每天焦虑什么，不是我自己决定的    ← 情绪词：焦虑
                ↓ 只换人称
标题       你每天焦虑什么，可能不是你自己决定的
                              ↑ 那是谁决定的？不说 —— 这就是缺口
```

🔴 **情绪版写对了，标题基本就是它换个人称。换完觉得不够劲，问题在情绪版，不在标题。**

### 🔴 情绪版里要有一个「已经付出的代价」（2026-09-22 加，实测）

**同一条内容，同一条路线，两个产出：**

| | 情绪版换人称的结果 | 判 |
|---|---|---|
| ❌ | 「AI 看着挺炫，可它到底能帮你做什么」 | **泛**。它只描述了困惑，观众听完没有损失感 |
| 🟢 | 「**学了一堆 AI 课，但好像没变化**」 | **有投入（学了一堆）、有落差（没变化）**，自带沉没成本 |

🔑 **差别不在句式，在有没有一个他已经交出去的东西。**
困惑是免费的，**代价不是** —— 一个已经花过时间或钱的人，才会想知道为什么白花了。

🔴 **判据（写完情绪版问一句）**：
## **这句话里，他已经付出过什么？**
　答得出（时间 / 钱 / 一堆课 / 半年 / 六十条视频）= 过
　答不出（只有「不知道」「搞不懂」「很迷茫」）= **还差一层**，回去找那个投入

⚠️ **代价必须是他真的已经付出的，不是你替他设想的后果**（同 `feedback_rules C13` / `裁定 #18`）。

**起标题前先验两条**：
- [ ] **语义跃迁**：情绪版里还是认知词（想/判断/逻辑/信息）？→ 回去重写，别在标题上使劲
- [ ] **时效性**：那个情绪是他**此刻正在承受**的吗？<br>
      ✅ 焦虑 / 心里没底 / 卡着 / 定不下来 / 睡不着　❌ 后悔 / 弯路 / 学费（回望型）

⚠️ **实测（N20 v5）**：从①抬产出《你越想越对，不是因为你想对了》——
**「越想越对」是认知现象，不是任何人每天在承受的东西。标题怎么改都救不回来，得回去改 ④。**

🔴 **没有落点句就不要起标题。** 直接从内容里挑一句听着响的，
产出的是「听着有道理」的标题，不是「这说的就是我」的标题。
📄 `aikey-topic/references/常识缺口法.md` §④ 落点句

## 说给谁听

**单人自采自编的知识型创作者。** 三条硬约束（与商业集同源）：

1. **不假设他有团队。** 拍摄、剪辑、发布都是他一个人，方案要能一个人执行完
2. **不用向上汇报。** 他自己拍板，直接给判断和动作，不写「供参考」
3. **零术语。** 理论照用，名词不出现——不说「信息缺口」，说「让他先觉得自己不知道」

## 平台不是一个口径

### 先分信息流：单列还是双列（2026-10-12 加）

**标题在哪种信息流里被看到，决定它干什么活。**

| | 单列（抖音、视频号） | 双列（小红书） |
|---|---|---|
| 观众看到标题时 | **视频已经在放了**，他已经刷到了 | 只看到一张缩略图 + 一行标题，**还没点** |
| 标题的活 | 帮他**留下来**、记住这条：金句、核心判断、观看价值 | 跟旁边那张图**抢点击** |
| 能不能把结论说出来 | **可以。** 给出判断不算剧透，但正文要有判断之外的东西（凭什么、怎么来的） | **不能。** 答案说完就没人点了 |

⚠️ 这一条改写了下面「5 道关」第 1 关的适用范围：**「读完标题是『原来如此』就打回」只对双列严格成立**；单列平台上标题直接给判断是合法打法。

### 三平台各自的规格（默认顺序：抖音 → 视频号 → 小红书）

| | **抖音** | **视频号** | **小红书** |
|---|---|---|---|
| **作品标题** | **建议 ≤20 字，硬上限 30 字（含标点）**，出稿就数。优先用原文里能单独传出去的那句金句或判断 | 建议 ≤20 字（含标点）。可以说结论；优先**适合在微信里转发**的说法。内容天然指向家人、同事、客户时，**留住这层关系感** | **≤20 字封顶，标点算字**（App 端 emoji 占 1 字，最多 1 个）。具体场景 / 反差 / 数字 / 问题，**不说完答案**；必须自带背景，陌生人一眼知道在聊什么 |
| **封面字** | **两行**，每行 ≤6 字，合计 ≤12 字（账号有实测模板时以模板为准）。**上行写对象或事件，下行写问题或角度** | **三行**，每行 3–6 字，合计 12–18 字 | **三行**，每行 3–6 字，合计 12–18 字，每行是关键词短语不是长句 |
| **封面的活** | **主页目录索引**：准确比吸引重要。只看封面就要知道这条具体讲什么 | **争点击**：它还会出现在聊天、朋友圈和转发卡片里。封面摆出观众想看的东西，标题负责往深推或推翻它 | **给具体场景、痛点或结果**，悬念留给标题。事件本身够强就朴素陈述，不硬加反转 |
| **作品描述** | 60–150 字（复杂的最多 200）；第一行直接进冲突或场景；只留 2–3 个要点；话题 1–3 个（同规则卡「上传三栏」：不加行业大词） | 80–180 字（最多 220）；中间讲清「为什么值得转给别人」；话题最多 3 个，默认不加 | 180–350 字；开头 2–3 行给冲突或反常识事实，中间短段落 / 编号，保留一个最有力的案例；话题 3–5 个，同样不加行业大词 |

封面字三个平台通用的禁区：**不写「真相 / 方法论 / 认知 / 干货 / 底层逻辑 / 颠覆认知」这类空词** —— 换哪条视频都能用的词，等于什么都没说。

🔴 **抖音封面写之前先在心里答一句**：「这条视频具体在讲**谁或什么事**，围绕它讨论**什么问题**？」答案压成两行就是封面。答不出这句，说明还没想清楚这条讲什么，先别写封面。

**用户没说发哪个平台 → 默认三个平台都出，按抖音、视频号、小红书的顺序，不再问。** 用户只说了一个平台就只出那一个。公众号、B 站、快手等其他平台，**用户当次明确提了才加**。

⚠️ 三个平台要**真的适配**：同一份标题 / 描述换个平台名复制三遍 = 没做。

## 红线层（这是本技能真正的核心价值）

写之前先把这几类写法**筛掉或改写**——很多流行的标题写法建在红线雷区上：

1. **卖真**：禁「月入过万 / 90 天赚 5 万 / 年入百万」这类**具体收益承诺**。可保留结果承诺公式，但换成守真的说法（见 `config.redlines.sell_real.allowed_phrasings`）。公域标题不出现具体收入金额。
2. **违禁词**：标题里禁「最 / 第一 / 唯一 / 全网」（违禁词避雷表）。结构库里凡带「最」「唯一」的示例，用时替换（「最根本原因」→「真正的原因」「被忽略的原因」）。
   **这条不只是合规，也是效果**：两个风格互不相同的抖音对标池上同向——池 A（n=541）含绝对化词的标题 save_intent 只有其余的 **0.53×**，池 B（n=259）**0.72×**（R2，实证规律库）。观众本身就不买账。⚠️ 但该特征在**本人 X 账号上是正相关**，**禁止跨平台套用**。
3. **不点名**：借名人势的写法，名人换成可说的（可提 OpenAI/Claude 品牌，不点 `config.redlines.no_naming.targets` 里的人）。
4. **编程词汇禁令**（B 端向）：封面 / 标题不出现「编程 / 写代码 / 命令行 / 程序员」，说结果不说手段（「让 AI 替你干活」而非「教你写代码」）。例外见家族公约六（照念型/泛人群靶子题）。
5. **文风**：不要英文冒号式标题（`标题：副标` 用中文全角或重写），不用英文直引号 `""`（口径以家族公约 §三.5 为准，引号与强调用弯引号 “ ”）。

**过不了红线的公式不给。给之前每条自己过一遍这五点。**

## 标题出手前的 5 道关（全平台）

1. **点进来还有没有东西可看**：标题把结论交代完了，正文就成了复读机。自测：读完标题，脑子里是「原来如此」还是「然后呢」？前者打回。
   - **单列平台（抖音、视频号）放宽**：标题可以直接给判断，自测换成「读完标题，他想不想知道**凭什么**？」不想 = 打回。见上方「先分信息流」。
2. **推送池够不够大**：标题里每一个圈内词（知识付费 / 私域 / SaaS）都在把可能被推到的人筛掉一批；换成圈外人也有感的词（搞钱 / 涨粉 / 不上班 / 一个人）。
3. **戳的是痛处还是名词**：「一人公司」是个名词，「不上班也能养活自己」才是痛处；「内容自动化」是个名词，「不想天天憋选题」才是痛处。标题里出现的应该是后者。
   - 🔴 **「戳别人的毛病」也不算戳痛处**（2026-09-22 加，实测）：「那些课只教你打字」戳的是**课的毛病**，「学了一堆课但好像没变化」戳的是**他自己的处境**。
     **前者要他先同意你对第三方的判断，才轮到他关心自己；后者第一秒就是他。**
     判据：**标题的主语，是他，还是你要批评的那个东西？** 是后者 = 还差一层，再往他身上落一次。
4. **有没有拉力**：对比 / 具体数字 / 悬念 / 冲突争议 / 时间承诺 / 结果承诺，六种拉力里一条标题至少要占两种，只占一种就是平铺。
   - **「具体数字」有条件成立，不是万能项**（R1，实证规律库）：在一个 n=541 的对标池上，带数字 1.73×、数字加量词单位 2.33×；但换一个风格不同的独立池（n=259）**完全不复现**（0.88× / 1.09×）——那个账号根本不用数字标题。
     正确读法：数字+量词是**清单型 / 步骤型 / 可量化结果型内容的伴随特征**，不是普适法则。**这条内容本身是那一类，才用；不是，就别为套公式硬凑数字**（凑了还可能撞卖真红线）。
   - 「结果承诺」⚠️ **未经实证**：池 A 无正向证据（1.00×）。可以用，但别当强项。
5. **卡字数**：小红书 ≤20 字含标点，超了就砍。（平台展示规范，非实测结论。）
   - **抖音封面**：以 `{vault}` 里该账号的实测出图模板为准；没有模板时按每行 ≤6 字。
     ⚠️ **模板存在时以模板为准** —— 例如某账号的两行版模板实测是**上行 ≤8 字、下行 ≤6 字**，按 6 字一刀切会砍掉能放的信息。
   - **视频号 / 小红书封面**：三行，每行 3–6 字，合计 12–18 字。

### 再问三句：这条能不能被传出去（2026-10-12 加）

5 道关管的是「点不点」，这三句管的是「看完之后会发生什么」：

1. **他会转给谁？** 说得出一个具体的人（老婆、合伙人、正在报课的朋友）= 有传播动作。说不出 → 看看原文里有没有天然指向某种关系的素材，把它留进标题或描述
2. **他以后在什么场景里会再想起这条？** 一个会重复发生的生活场景（又一次被推销课、又一次开周会）比一次性的事件更能让内容被记住
3. **传出去以后，别人还知不知道是谁说的、这个人能提供什么？** 内容里有故事时，作者是不是那个拆不掉的角色；标题把作者拆掉了，传得再远也是替别人传

三句都只能**从原文已有的素材里找**。原文只是平铺的知识，就去原文里找具体场景、数字、对比和后果，**不编一个更刺激的案例**。

### 标题、封面、描述各干各的活（2026-10-12 加）

| | 干什么 | 不干什么 |
|---|---|---|
| **标题** | 提问题、制造悬念，或者把观点钉死 | 不负责概括全文 |
| **封面字** | 说清**具体对象、场景、冲突或结果** | **不是标题的缩写** |
| **描述** | 第一句接住最强的那个冲突；说明为什么值得看下去；提炼关键判断或行动清单 | 不是把逐字稿再贴一遍；不改成「AI 总结腔」；不编原文没有的数据、经历、身份、结果 |

封面和标题同时出现时要**互补**，同一个信息说两遍就浪费了一个位置。
⚠️ 这是默认，不是禁令：账号主人可以**主动选择**标题和封面用同一句（作者账号上发生过）。**想过之后选同一句可以，忘了改不行。**

## 🔴 从观众那端写，不是从内容那端写（2026-09-22 加，本技能被真实打败过一次）

**同一条稿，技能给了三个押注，用户自己随口提了一个，评完之后用户那个排第一。**

| | 技能给的 | 用户给的 |
|---|---|---|
| 标题 | 《AI 课教来教去，就教你打字》 | 《**为什么学了一堆 AI 课，但好像没变化**》 |
| 它从哪儿长出来 | **内容的判断**（那些课有什么毛病） | **观众的处境**（我投了，但没变） |
| 观众要做的第一件事 | **先同意我对第三方的判断**，才轮到他关心自己 | **第一秒就认出自己** |
| 推送池 | 中（带一点评判语气） | **最宽**（零圈内词，谁都懂） |

🔑 **这不是「他更懂自己的账号」，是一个可复制的位置差：**
## **标题站在内容这一端，观众要走一步才够得着；站在观众那一端，他不用走。**

### 出手前的最后一问（加在 5 道关之后）

> ## **这句标题的主语，是观众的处境，还是我要讲的那个东西？**

是后者 ⇒ 不一定要否掉，但**必须再写一版从观众那端起手的**，然后两个并排比。
**不要只给从内容那端长出来的那一批** —— 那是本技能已经被实测打败过一次的地方。

### ⚠️ 一个容易顺手写坏的地方：留不留余地

用户那条标题里有两个字是关键：**「好像」**。

- 「学了一堆 AI 课，**没有**变化」= 断定他失败了 ⇒ 他要先承认自己不行才能点进来
- 「学了一堆 AI 课，**好像没**变化」= 留了余地 ⇒ **他不用承认什么就能点进来**

🔴 **判据**：**这句标题成立，需不需要他先认领一个不体面的身份？**
需要 = 加一个松动词（好像 / 似乎 / 总觉得 / 是不是），或者换主语。
📌 这是把两条规矩落到标题层的具体手法：不要让观众先承认自己惨，以及通篇零说教。

## 工作流程

**Step 0：片子拍到哪一步了（2026-10-10 加）。** 按 `references/拍摄进度分档.md` 判这条在哪一档：只发文字 / 还没拍 / 拍完能补拍 / 拍完不能补拍 / 从长录像里切。**上下文看得出就不问**，看不出用选择题问一次。档位决定标题能承诺多少：**拍完的片子，只承诺片子里已经说到的**；第 4、5 档每个候选都要标出对应片子里哪一句。

**Step 1：确认话题 + 人群（缺哪个问哪个，一次一个）；平台没说就默认抖音、视频号、小红书三个都出。** 先在心里答清五件事再动手：讲的**具体对象**、最容易被击中的**观众**、原文里**最强的那个钩子**（最具体、最反常识或最有情绪冲击的事实 / 数字 / 场景 / 金句）、观众真正在意的**结果**、他会**转给谁**。用户贴了一段内容 → 先提取核心话题和素材（数据 / 反差 / 金句）再进 Step 2。

**Step 2：选结构（动手）。** 先判断**这条内容本身是什么形状**（清单型？推翻通念型？亲历型？），再从 S1–S12 里挑 3–5 个**匹配这个形状**的结构，各写一个候选。

**已经有标题的，它就是候选 0（2026-10-10 加）。** 用户贴的、稿子里写着的、上次发过的，都算。候选 0 同样标结构编号、过红线；它要是有发布数据（点击、完播、收藏），一起带上。之后每个新候选都要写一句**它比候选 0 强在哪一点**（推送池更宽 / 主语换到了观众那端 / 多了一个他已经付出的代价……）。**说不出具体的一点 → 押候选 0**，不为了显得做了事而换掉一个能用的标题。候选 0 不享受豁免：手上有落点句时，它同样要对照落点句看押没押中 —— 没押中，这一点就是新候选强过它的地方。

**不要为了凑数量把不匹配的结构硬套上去**——一条讲个人经历的内容硬做成「5 个方法」，标题和内容对不上，点进来的人会立刻走。

**Step 3：生成 + 说明（停）。** 每个标题：标结构编号（S1–S12）→ 一句话说**为什么这个结构配这条内容** → 标红线是否过、改写了哪处。

**不引用任何「原始爆款」做背书**——别人的爆款不能证明你的标题会好，那正是这个库推翻掉的东西。

**Step 4：每个平台 5 个标题 + 5 个封面，各选 1 个首选。** 5 个候选要有**真的角度差异**（金句 / 本质判断 / 具体冲突 / 场景 / 关系 / 观看价值 / 行动指向 / 结果期待……每个平台至少覆盖 3 种）。换近义词、调语序凑数不算。**首选必须由你选**，不把挑选的活全丢给用户；首选旁边写一句为什么押它，再点一句另外两个最强的备选各换来什么（有的换评论区吵起来，有的换点击），让他按目标改。抖音的 5 个封面是**同一个主题的不同索引说法**，首选挑最准的那个；视频号、小红书的 5 个封面要用不同的切入点。

输出格式（先用不超过 5 行说内容判断：核心命题、最强钩子、真实痛点、会转给谁、以后会在什么场景想起；然后按平台顺序出）：

## 特殊情况
- **优化已有标题**：原标题按 Step 2 当候选 0 → 先判断它用了哪个结构（哪怕用户自己不知道）→ 判断这个结构配不配这条内容 → 换结构，或在同结构内改具体表达。**新写的说不出比它强在哪，结论就是「原标题不用改」**，这是一个合格的结论。
- **只想浏览有哪些写法**：给 S1–S12 速查表（见结构库），**并说清它是词汇表不是排行榜**，没有哪个天生更好。
- **话题还没定**：反过来从观众入手，问他希望刷到的人第一反应是什么（想知道原因 / 心里一紧 / 「这说的就是我」/ 想学），用这个反应倒推该用哪类结构。

## 绝对不做
- 不给说不出结构编号和理由的标题。
- **不声称某个结构「更容易火」**——12 个结构零跨源复现，这么说就是编。要给效果判断，只能基于用户自己的数据（`scripts/title_struct.py` 可以跑）。
- 不给过不了卖真 / 违禁词 / 不点名 / 编程词汇红线的标题。
- 不改公式的底层逻辑（「为什么 X 其实有害」的内核是反常识，不能改成不反常识的）。
- 不超字数还硬塞。
