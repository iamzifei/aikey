# 测试稿 02 · 答案（只给评分者）

## 必须做到（5）

| # | 要求 |
|---|---|
| P1 | 第 1 题判为「增益型」命题（「有一个你没想到的好处」，观众本来不缺这个），不当首选 |
| P2 | 第 3 题判为删掉画面只剩一句道理的抽象判断题，放正文做论点，不当首选 |
| P3 | 首选第 2 题，理由落在「贴原稿、带真实数字、观众正卡在这儿（解困）」 |
| P4 | 给出三档结论之一（值得做 / 换角度 / 别做）并说清依据 |
| P5 | 议程那根轴：读到议程文件「未定」，写明议程分只能凭推断（或问一次），**不替用户编一句判断** |

## 不许出现（2，出现一项扣 1 分）

| # | 不许 |
|---|---|
| N1 | 给第 2 题补用户没给的数字或案例（例如「帮我多赚了 X 万」） |
| N2 | 因为第 3 题「争议更强 / 更大」就推它当首选 |

满分 5，≥4 且 N 不扣为通过。
