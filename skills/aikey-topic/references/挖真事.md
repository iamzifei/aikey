# 挖真事：手里没素材时，一问一答把真事问出来

> 用在：他说「不知道拍什么」「最近没什么可讲的」，或者选题依赖的一手素材是空的。
> 不用在：手里已经有稿、有素材，只想判断能不能做 —— 那走模式 A / B。
> 这不是新的关：他不想聊，直接回到原来的选题流程。

## 为什么要问，而不是让他自己想

人对自己经历过的事有「这不值一提」的盲区。让他「想想最近有什么素材」，他会回答「没什么」；
问他「今天谁让你最头疼」，他会讲十分钟。**缺的不是事，是一个具体的问题。**

## 怎么问（五条，比流程重要）

1. **一轮只问一个问题。** 最多带半句引导或一个例子。
2. **问「那一次」，不问「平时」。** ❌「你一般怎么跟客户沟通？」✅「这周哪个客户让你回完消息还在想？他原话怎么说的？」
3. **先接一句再问。** 他说完，先用半句话接住（「这个确实憋屈」），再问下一个。不要像填表。
4. **答不上来就把门槛放低。** 他说「没有」，就换成按时间走：「那今天从早上开始，第一件让你停下来的事是什么？」再不行，给 2–3 个选项让他挑。
5. **不评判、不补细节。** 他吐槽员工、跟客户吵架，只管问下去；所有细节都得是他说出口的，没问到的就是没有。

## 从哪里下第一刀

按这个顺序试，哪个有回应就顺着往下：
- **最近一次被问倒**：客户 / 学员 / 朋友问了一个他一时答不上的问题；
- **最近一次改主意**：本来打算 A，后来做了 B，中间发生了什么；
- **最近一次算账**：花了多少、赚了多少、哪笔让他意外；
- **最近一次被误解**：别人以为他在做什么，实际在做什么；
- **今天按时间走一遍**：从早上到现在，哪一刻停下来想了一下。

## 挖到什么程度算「够了」

一件事同时有下面四样，就停止追问，先出卡：
- **一个具体的人**（不必有名字，有身份）；
- **一句原话**；
- **一个数字或一个看得见的细节**；
- **一个意外**：结果和他原来以为的不一样。

缺哪样只追问哪样，最多再问两轮。还是缺 → 照样出卡，缺的那格标【待补：X】，不编。

## 出卡：一条一张

```
素材卡 · {一句话说清这事}
人：{谁}
原话：「{他说的原话}」
数字 / 细节：{…}
意外在哪：{原来以为 → 实际}
缺：{【待补：X】，没有就写「无」}
风险：{会不会让当事人难堪、能不能公开、有没有点名 —— 只提醒，不替他决定}
```

出完卡**马上推 2–3 个选题**，走模式 B 的供需判定，然后问他「接着挖下一条，还是先拿这条写？」。
素材卡落盘到 `01-原始素材区/我的素材/_待确认/`，一张一个文件（家族公约 §五.5）。**作者核对过原话、补齐【待补】之后**，才挪进 `我的素材/` 正式层；写稿技能只认正式层。

## 不做的

- 不一次甩一串问题；不用「素材」「冲突」「人设」这类词跟他说话。
- 不替他补人物动机、不替他编对话。
- 不因为挖不出来就降低卖真红线去「合理想象」。
