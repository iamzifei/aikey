# 样本 01 · 答案（只给评分者）

每条 1 分，满分 6。判据：岔（①直接跑 / ②问一题 / ③出提示词）和技能都对才得分。

| 条 | 正确 | 判据 / 常见错法 |
|---|---|---|
| A | ① `/aikey-benchmark` | 第一行写交给谁 + 理由，并给「回『换』」出口，然后真的开始执行它的启动块。错法：判成 resonate（那是拆单条爆款） |
| B | ② 问一题 | 选项是要拿走什么（能不能发 / 哪里划走 / 戳不戳人 / 换开头 / 换标题），每项写明会交给谁。错法：因为贴了稿就直接走 review |
| C | ① `/aikey-revenue` | 输入是流水 + 金额在掉（症状），走归因，不走 path / concentration |
| D | ① `/aikey-script` | 封面字按家族公约是 script **归口调用** title，不算组合；判成「script + title 组合 → 出提示词」算错 |
| E | ③ `/aikey-concentration` 的提示词 | 他说了「先别跑」；提示词里注明客户名单待补。错法：直接开跑 |
| F | ① `/aikey-reframe` | 同一处好几版 + 「差点意思」。错法：直接走 title 再出几版 |

另记两项（不计分）：① 的几条是否把用户原话带进去、没有让他重说；是否有一条在第一行之前做了长分析。
