# 问题探寻与共鸣

本文件是三路选题共用的生成步骤。先找到值得回答的问题，再选表达结构。适用于出新题、单题诊断和找拉力；不替代定位、事实核实、供需判断与去重。

## 1．钉住现象，不接受问题里的结论

把输入拆成「谁，在什么情境下，做了什么，期待什么，实际观察到什么」。只写材料支持的部分；缺的标待核，不补成客户原话或亲历案例。用户只给宽泛方向时，可先生成待验证的问题，不必把问题清单当访谈问卷抛回去。

遇到「落地、信任、专业、焦虑、效率」等大词，暂时不用这个词，改写成能观察的行为。例如「缺乏信任」可能是未付定金、未交资料，也可能只是询问过却未继续；这三件事不能互相代替。

找出问题暗含的一条关键假设，包括作者自己的假设：

- 是事实，还是把解释写成了事实？「没成交」不自动等于「不信任」。
- 是手段，还是最终目标？「要更多内容」究竟为获得咨询，还是减少制作时间？
- 是能力，还是结果？「能生成答案」是否等于「能完成客户的任务」？
- 是普遍不成立，还是某个条件变了？一个反例只够推翻对应范围的断言。

**怀疑应能改变解释或行动。** 不为了反常识而反常识，不预设观众错、作者对；答案也可以是原判断成立、只在特定条件成立，或证据不足。

## 2．用不同解释互相检验

涉及原因或机制时，提出 2–3 个会导向不同动作的解释，不用近义词凑数。对每个解释问：它如何导致现象？什么观察会削弱它？哪条最小证据能把它与其他解释分开？

例如「有 IT 团队仍找外援」可能涉及交付质量、排期或业务定义。不能只凭这个现象断言团队技术差，更不能宣布「老板都不需要学 AI」。应回到对话记录或具体交付差距区分。

区分两个任务：解释「为什么发生」需要证据；解决「接下来怎么办」还需要现实中的尝试和反馈。推理顺畅不等于方案有效。理论用于解释或提出可检查的预测，不用于装饰预先决定的结论。

已有充分证据的简单问题不用强造多个解释。缺少证据时，保留问题与最有区分力的待核项，不能把猜测写进肯定式标题。

## 3．把问题接到观众自己的选择

写一句：**「我想要＿＿，但在＿＿处境下，我不知道该不该／能不能／为什么＿＿。」**

这个「我」是目标观众，不自动等于作者。真实原话标来源；代拟内心话明确标「推测」，不能当用户调研。用它检验：

- **目标与代价**：答案关系到他什么在意的东西？钱、时间、专业价值、控制感或别的具体利益？
- **眼前处境**：什么使他此刻难以决定？现有做法有何合理性，又卡在哪里？
- **未解选择**：听完会多理解什么，或者能够改变哪项判断？

每题挑一个主要共鸣点。好奇、松一口气、被理解和重新看见选择都可以；不必制造焦虑或指责。写出「焦虑」不等于产生共鸣，没有情绪词也可能命中利益和处境。

作者的反差经历可以是证据或入口，但不能代替观众为什么要听。把解释段盖住，只读钩子，还应看得见一个值得知道的答案。

## 4．用问题动作生成角度，再压成钩子

下表是生成支架，不是爆款公式。按材料选择，不必每次用全；几个候选应有不同的未解问题，不能只给同一个结论换人称。发布标题仍交 zmm-title。

| 问题动作 | 从材料追问什么 | 必须保留的边界 |
|---|---|---|
| 价值替代 | 当 X 也能做到，为什么还需要 Y？ | 先核实二者是否真在完成同一任务 |
| 路径去留 | 条件变了，原来的做法还值得继续吗？ | 不把局部变化扩大成整个职业过时 |
| 投入回报 | 更多、更快、更熟练，是否真的更接近目标？ | 写清目标，不以情绪代替回报证据 |
| 约束可行性 | 不做 X 或缺少 X，还能达到 Y 吗？ | 区分必要条件、常用办法和可替代办法 |
| 原因辨别 | 同样的表象，究竟是哪种原因在起作用？ | 给出区分证据，不能只卖「真正原因」 |
| 问题重定 | 我一直想解决 X，实际卡住的会不会是 Y？ | 用现象支持重定，不能绕过用户目标 |

一条候选内部保留四项即可：**未解问题 → 主要解释及待核项 → 观众处境 → 正文如何兑现**。正式候选格式沿用 SKILL.md；不要把全部分析表输出给只想看几个题目的用户。

钩子检验：①不靠补充说明也能理解；②值得知道但没有偷塞未经证实的前提；③正文有可提供的证据、比较或行动方法；④契合定位，不能只凭猎奇混入目标客户不关心的议题。

问句不是免责符。「你为什么一直被骗」仍预设受骗；「X 过时了吗」若正文只会说「看情况」也没有兑现。无法回答的保留为研究题，不能进入 Ready。

## 与旧流程衔接

- 三路选择输入处理方式，本文件负责共同的假设检查、解释比较和共鸣转换。
- 常识缺口法适合检验已有认知；只有证据显示常识失效时，才用「走到死路」。探索未知、验证常识成立，也能产出选题。
- 「情绪版换人称」保留为一种表达路线；有具体利害和未解选择的问句不必改成情绪词。词面结构与问题动作是两层，不能互相替代。
- 供需效果、点击和转化需要真实反馈。用户喜欢某组钩子，只支持该次偏好，不能证明整个方法胜出。

## 方法范围与验证状态

本流程组合可观察现象、默认假设与竞争解释，区分词语使用情境、解释与行动，检查目标相关性、处境与控制感，并用价值、去留、投入和可行性问题生成候选。运行不依赖外部技能包。

不采用整套固定打分、固定商业结论或跨平台效果承诺。该次用户对 4 个钩子的认可是修改动机，不是本流程的传播效果验证。
